## 封装与访问修饰符

### 封装的概念

封装 = **隐藏内部细节 + 暴露受控接口**。核心做法：用 `private` 修饰成员变量，用 `public` 的 getter/setter 访问。

```java
public class BankAccount {
    private double balance;   // 私有 — 外部不能直接访问

    // getter — 读取余额
    public double getBalance() {
        return balance;
    }

    // setter — 存钱（带校验）
    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }
}
// 外部无法直接修改 balance，只能通过 deposit 方法
```

### 四种访问修饰符

| 修饰符 | 本类 | 同包 | 子类 | 所有 |
|--------|------|------|------|------|
| `private` | ✓ | ✗ | ✗ | ✗ |
| 默认（无修饰符）| ✓ | ✓ | ✗ | ✗ |
| `protected` | ✓ | ✓ | ✓ | ✗ |
| `public` | ✓ | ✓ | ✓ | ✓ |

### 封装的优点

- 数据安全：防止外部直接修改（如 age 设置为 -5）
- 灵活修改：内部实现改变不影响外部调用
- 可加校验：setter 中可以验证数据合法性

### 小结

- 成员变量用 `private`
- 提供 `public` 的 getter/setter
- 验证逻辑放在 setter 中
