## 实例属性与方法

### 实例属性

实例属性绑定在 `self` 上，每个对象独立拥有。

```python
class Book:
    def __init__(self, title, author):
        self.title = title      # 必须在 __init__ 中声明
        self.author = author
        self._page = 0          # 约定：_ 开头表示"受保护"

# 动态添加属性（不推荐但可行）
b = Book("Python入门", "张三")
b.publisher = "出版社A"  # 动态添加
print(b.publisher)
```

### 属性访问控制

```python
class User:
    def __init__(self, name, password):
        self.name = name           # 公开
        self._email = ""           # 约定受保护（实际仍可访问）
        self.__password = password # 名称改写为 _User__password

u = User("admin", "123456")
print(u.name)       # admin ✅
print(u._email)     # "" ✅ 可访问，但约定不要直接访问
# print(u.__password) # AttributeError! ❌
print(u._User__password)  # 123456 ⚠️ 实际可以这样访问（名称改写）
```

### 实例方法

```python
class Calculator:
    def __init__(self):
        self.result = 0

    def add(self, value):
        """实例方法 — 第一个参数是 self"""
        self.result += value
        return self

    def subtract(self, value):
        self.result -= value
        return self     # 返回 self 支持链式调用

    def get_result(self):
        return self.result

# 链式调用
calc = Calculator()
result = calc.add(10).subtract(3).add(5).get_result()
print(result)  # 12
```

### 属性验证

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.set_score(score)  # 通过方法设置以验证

    def set_score(self, value):
        if not 0 <= value <= 100:
            raise ValueError("分数必须在0-100之间")
        self._score = value

    def get_score(self):
        return self._score
```

### 小结

- 实例属性在 `__init__` 中声明，通过 `self.xxx` 访问
- `_single` 约定受保护，`__double` 名称改写
- 返回 `self` 支持链式调用
- 使用 getter/setter 方法验证属性值
