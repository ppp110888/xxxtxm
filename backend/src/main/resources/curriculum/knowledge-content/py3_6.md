## Lambda 与函数式编程

### Lambda 表达式

```python
# 语法：lambda 参数: 表达式
add = lambda a, b: a + b
print(add(3, 5))  # 8

# 常用场景：排序 key
students = [("小明", 85), ("小红", 92), ("小刚", 78)]
students.sort(key=lambda s: s[1])  # 按分数排序
sorted_list = sorted(students, key=lambda s: s[1], reverse=True)
```

### map — 映射

```python
nums = [1, 2, 3, 4, 5]

# 使用 lambda
squares = list(map(lambda x: x**2, nums))
# [1, 4, 9, 16, 25]

# 等价推导式（更 Pythonic）
squares = [x**2 for x in nums]
```

### filter — 过滤

```python
nums = [1, 2, 3, 4, 5, 6, 7, 8]

# 使用 lambda
evens = list(filter(lambda x: x % 2 == 0, nums))
# [2, 4, 6, 8]

# 等价推导式
evens = [x for x in nums if x % 2 == 0]
```

### reduce — 归约

```python
from functools import reduce

nums = [1, 2, 3, 4, 5]
total = reduce(lambda acc, x: acc + x, nums)  # 15
product = reduce(lambda acc, x: acc * x, nums)  # 120
```

### 函数作为一等公民

```python
# 函数可以赋值给变量
def greet(name):
    return f"你好, {name}!"

say_hi = greet
print(say_hi("小明"))  # 你好, 小明!

# 函数可以作为参数
def apply(func, value):
    return func(value)

print(apply(lambda x: x**2, 5))  # 25

# 函数可以返回函数
def make_adder(n):
    return lambda x: x + n

add5 = make_adder(5)
print(add5(10))  # 15
```

### 小结

- `lambda` 用于简短匿名函数
- `map` 映射、`filter` 过滤、`reduce` 归约
- 在大多数场景，推导式比 map/filter 更 Pythonic
- Python 中函数是一等公民
