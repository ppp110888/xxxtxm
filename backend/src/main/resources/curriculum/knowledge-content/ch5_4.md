## 缓冲流

### 为什么需要缓冲？

不带缓冲的流每次读写都访问磁盘，效率极低。缓冲流内部维护一个缓冲区，**批量读取/写入**，大幅提升性能。

### BufferedReader

```java
// 逐行读取（比 FileReader 快很多）
try (BufferedReader reader = new BufferedReader(
        new FileReader("input.txt", StandardCharsets.UTF_8))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
}

// 读取所有行（Java 8+）
List<String> allLines = Files.readAllLines(Path.of("input.txt"));
```

### BufferedWriter

```java
try (BufferedWriter writer = new BufferedWriter(
        new FileWriter("output.txt", StandardCharsets.UTF_8))) {
    writer.write("第一行");
    writer.newLine();      // 跨平台换行
    writer.write("第二行");
}
```

### 套接装饰模式

```java
// BufferedReader 包装了 FileReader，增强了功能
new BufferedReader(new FileReader("file.txt"))
//   装饰器            被装饰者
```

### 小结

- 缓冲流大幅提升 IO 性能
- BufferedReader.readLine() 逐行读取
- 缓冲流是装饰器模式的应用
