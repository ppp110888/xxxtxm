## 继承与多态

### 继承

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

class Dog(Animal):          # Dog 继承 Animal
    def speak(self):        # 重写父类方法
        return "汪汪！"

class Cat(Animal):
    def speak(self):
        return "喵喵！"
```

### super() — 调用父类方法

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

class Student(Person):
    def __init__(self, name, age, student_id):
        super().__init__(name, age)  # 调用父类 __init__
        self.student_id = student_id

    def info(self):
        return f"{self.name}, {self.age}岁, 学号{self.student_id}"
```

### 多继承

```python
class Flyable:
    def fly(self):
        return "飞行中"

class Swimmable:
    def swim(self):
        return "游泳中"

class Duck(Flyable, Swimmable):
    def quack(self):
        return "嘎嘎！"

d = Duck()
print(d.fly())   # 飞行中
print(d.swim())  # 游泳中
```

### 多态 — 鸭子类型

"If it walks like a duck and quacks like a duck, it's a duck."

```python
# 不关心类型，只关心行为
def make_sound(animal):
    return animal.speak()

print(make_sound(Dog("旺财")))  # 汪汪！
print(make_sound(Cat("咪咪")))  # 喵喵！

# 甚至不是 Animal 子类也行
class Car:
    def speak(self):
        return "滴滴！"

print(make_sound(Car()))  # 滴滴！
```

### 类型检查

```python
d = Dog("旺财")
print(isinstance(d, Dog))     # True
print(isinstance(d, Animal))  # True — 子类实例也是父类实例
print(issubclass(Dog, Animal))  # True
print(type(d))                # <class '__main__.Dog'>
```

### 常见错误

- ❌ 忘记调用 `super().__init__()`
- ❌ 多继承方法解析顺序混淆
- ✅ 使用 `isinstance()` 而非 `type() ==`

### 小结

- 继承实现代码复用，`class Child(Parent):`
- `super()` 调用父类方法
- Python 支持多继承，MRO 决定方法查找顺序
- 多态靠"鸭子类型" — 不关心类型，只关心行为
