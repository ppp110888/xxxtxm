# 第4章 集合框架

> 集合是 Java 中最常用的数据结构。数组长度固定，而集合可以动态增长。

## 本章目标

1. 理解集合框架的整体架构（Collection / Map 两大体系）
2. 掌握 List、Set、Map 三大接口及其常用实现类
3. 理解 hashCode 和 equals 的关系
4. 掌握 Collections 工具类的使用
5. 理解泛型在集合中的应用
