## 循环结构 for / while

### for 循环

Python 的 `for` 循环用于遍历**可迭代对象**：

```python
# 遍历列表
fruits = ["苹果", "香蕉", "橘子"]
for fruit in fruits:
    print(fruit)

# range() 生成数字序列
for i in range(5):      # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 6):   # 1, 2, 3, 4, 5  (从1开始，到5结束)
    print(i)

for i in range(0, 10, 2):  # 0, 2, 4, 6, 8  (步长为2)
    print(i)

# 遍历字典
student = {"name": "小明", "age": 18}
for key, value in student.items():
    print(f"{key}: {value}")
```

### while 循环

```python
# 基本 while
count = 0
while count < 5:
    print(count)
    count += 1

# while + else（循环正常结束时执行）
n = 3
while n > 0:
    print(n)
    n -= 1
else:
    print("倒计时结束！")
```

### break 和 continue

```python
# break — 跳出循环
for i in range(10):
    if i == 5:
        break       # 直接退出循环
    print(i)        # 输出 0~4

# continue — 跳过本次迭代
for i in range(5):
    if i == 2:
        continue    # 跳过 i=2
    print(i)        # 输出 0, 1, 3, 4
```

### enumerate — 同时获取索引和值

```python
fruits = ["苹果", "香蕉", "橘子"]
for i, fruit in enumerate(fruits):
    print(f"{i}: {fruit}")
# 0: 苹果
# 1: 香蕉
# 2: 橘子
```

### zip — 并行遍历

```python
names = ["小明", "小红", "小刚"]
scores = [85, 92, 78]
for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

### 常见错误

- ❌ 修改正在遍历的列表
- ❌ 忘记 `range` 的结束值不包含在内
- ✅ `range(n)` 生成 0 到 n-1

### 小结

- `for` 用于遍历可迭代对象
- `range(n)` 生成 0~n-1 整数序列
- `while` 当条件为 True 时持续执行
- `break` 退出循环，`continue` 跳过本次
- `enumerate` 和 `zip` 是循环的好帮手
