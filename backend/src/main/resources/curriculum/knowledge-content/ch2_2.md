## 成员变量与成员方法

### 成员变量 vs 局部变量

```java
public class Person {
    // 成员变量（在类中定义，有默认值）
    String name;    // 默认 null
    int age;        // 默认 0
    boolean isStudent; // 默认 false

    public void work() {
        // 局部变量（在方法中定义，必须初始化）
        int hours = 8;  // 没有默认值，必须赋值
        System.out.println(name + "工作了" + hours + "小时");
    }
}
```

### 成员变量默认值

| 类型 | 默认值 |
|------|--------|
| int/byte/short/long | `0` |
| float/double | `0.0` |
| boolean | `false` |
| char | `'\u0000'`（空字符） |
| 引用类型 | `null` |

### 成员方法的定义

```java
public class Calculator {
    // 无参数，有返回值
    public int getZero() {
        return 0;
    }

    // 有参数，有返回值
    public double divide(double a, double b) {
        if (b == 0) return 0;
        return a / b;
    }

    // 调用成员变量
    double lastResult = 0;

    public void add(double a, double b) {
        lastResult = a + b;  // 修改成员变量
        System.out.println(lastResult);
    }
}
```

### this 关键字

```java
public class Student {
    String name;

    // 当参数名和成员变量名相同时，用 this 区分
    public void setName(String name) {
        this.name = name;  // this.name 是成员变量，name 是参数
    }
}
```

### 小结

- 成员变量有默认值，局部变量没有
- 成员变量在类中定义，局部变量在方法中定义
- `this` 指代当前对象
