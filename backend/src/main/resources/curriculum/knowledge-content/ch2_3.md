## 构造方法

### 什么是构造方法？

构造方法是**创建对象时自动调用**的特殊方法，用于初始化对象。

```java
public class Student {
    String name;
    int age;

    // 构造方法（与类同名，无返回值）
    public Student() {
        System.out.println("学生对象被创建了！");
    }
}

Student s = new Student();  // 自动调用构造方法
```

### 带参数的构造方法

```java
public class Student {
    String name;
    int age;

    // 无参构造
    public Student() { }

    // 带参构造 — 创建对象时直接赋值
    public Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}

Student s1 = new Student();              // 调用无参构造
Student s2 = new Student("小明", 18);    // 调用带参构造
```

### 默认构造方法

```java
// 如果没有写任何构造方法，Java 自动提供一个无参构造（什么都不做）
public class Dog { }
Dog d = new Dog();  // OK — 使用默认构造

// 一旦写了构造方法，默认构造就没了！
public class Cat {
    public Cat(String name) { }  // 自定义构造
}
Cat c = new Cat();  // 编译错误！默认构造已被覆盖
```

### 构造方法重载

```java
public Student(String name) { this.name = name; }
public Student(String name, int age) { this.name = name; this.age = age; }
```

### 小结

- 构造方法与类同名，无返回值
- `new` 关键字触发构造方法
- 没写构造时 Java 提供默认无参构造
- 写了构造后默认构造消失，如需无参构造需手动写
