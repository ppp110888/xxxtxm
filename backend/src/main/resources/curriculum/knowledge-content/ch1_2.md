## 变量与数据类型

### 变量是什么？

**变量**是内存中一块被命名的存储空间，用来存放数据。你可以把变量想象成一个贴着标签的盒子。

```java
int age = 18;          // 声明一个 int 类型变量 age，赋值为 18
double price = 9.99;   // 声明一个 double 类型变量 price
String name = "小明";   // 声明一个字符串变量 name
```

### Java 的 8 种基本数据类型

| 类型 | 大小 | 范围 | 示例 |
|------|------|------|------|
| `byte` | 1 字节 | -128 ~ 127 | `byte b = 100;` |
| `short` | 2 字节 | -32768 ~ 32767 | `short s = 30000;` |
| `int` | 4 字节 | -2³¹ ~ 2³¹-1 (约±21亿) | `int i = 100000;` |
| `long` | 8 字节 | -2⁶³ ~ 2⁶³-1 | `long l = 100000L;` |
| `float` | 4 字节 | 单精度浮点数 | `float f = 3.14f;` |
| `double` | 8 字节 | 双精度浮点数 | `double d = 3.14159;` |
| `boolean` | 1 位 | `true` / `false` | `boolean ok = true;` |
| `char` | 2 字节 | Unicode 字符 0~65535 | `char c = 'A';` |

### 命名规则

```java
// ✅ 合法命名
int studentAge;     // 驼峰命名（推荐）
String firstName;   // 驼峰命名
int count2;         // 数字可用，但不能开头
double PI = 3.14;   // 常量用全大写

// ❌ 非法命名
int 2count;         // 不能以数字开头
int my-age;         // 不能有连字符
int class;          // 不能是关键字
```

### 类型转换

```java
// 自动类型转换（小 → 大）
int i = 10;
long l = i;         // int 自动转为 long ✅
double d = i;       // int 自动转为 double ✅

// 强制类型转换（大 → 小，可能丢失数据）
double pi = 3.14;
int n = (int) pi;   // n = 3，小数部分丢失

// 字符串转换
String s = "123";
int num = Integer.parseInt(s);  // 字符串 → int
String back = String.valueOf(num);  // int → 字符串
```

### 常见错误

- ❌ `int x = 3.14;` — 不能把 double 赋给 int
- ✅ `double x = 3.14;` 或 `int x = (int) 3.14;`

- ❌ `float f = 3.14;` — 3.14 默认为 double
- ✅ `float f = 3.14f;` — 加 f 后缀

### 小结

- 8 种基本类型：整型4种(byte/short/int/long)，浮点2种(float/double)，字符char，布尔boolean
- 变量名用驼峰命名法，不能以数字开头，不能是关键字
- 小类型→大类型自动转换，反之需强制转换
- 引用类型 `String` 不是基本类型，但非常常用
