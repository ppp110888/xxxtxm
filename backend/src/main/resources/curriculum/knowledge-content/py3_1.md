## 字典与集合

### 字典 dict

字典是**键值对**集合，无序（Python 3.7+ 保持插入顺序），**键必须可哈希**。

```python
# 创建
student = {"name": "小明", "age": 18, "score": 95}
empty = {}
data = dict(name="小明", age=18)

# 访问
student["name"]         # 小明
student.get("name")     # 小明
student.get("grade", "N/A")  # N/A — 键不存在时返回默认值

# 修改
student["age"] = 19     # 修改
student["grade"] = "A"  # 添加新键

# 遍历
for key in student:
    print(key)           # name, age, score, grade

for key, value in student.items():
    print(f"{key}: {value}")

for value in student.values():
    print(value)
```

### 字典操作

```python
# 删除
student.pop("grade")   # 删除并返回
del student["score"]    # 直接删除
student.popitem()       # 删除最后一项 (Python 3.7+)

# 合并
d1 = {"a": 1, "b": 2}
d2 = {"b": 3, "c": 4}
d3 = {**d1, **d2}   # {"a": 1, "b": 3, "c": 4} — 后者覆盖前者
d1.update(d2)        # d1 更新为 {"a": 1, "b": 3, "c": 4}

# 默认值
from collections import defaultdict
dd = defaultdict(int)
dd["count"] += 1  # 不存在时自动初始化为 0
```

### 集合 set

集合是**无序、不重复**的元素集合。

```python
# 创建
nums = {1, 2, 3, 4}
empty = set()

# 去重
unique = set([1, 2, 2, 3, 3, 3])  # {1, 2, 3}

# 集合运算
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

a | b   # {1, 2, 3, 4, 5, 6}  并集
a & b   # {3, 4}                交集
a - b   # {1, 2}                差集
a ^ b   # {1, 2, 5, 6}         对称差

# 方法
a.add(5)        # 添加元素
a.remove(3)     # 删除（不存在则报错）
a.discard(10)   # 删除（不存在不报错）
```

### 字典推导式

```python
squares = {x: x**2 for x in range(5)}
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 反转键值
original = {"a": 1, "b": 2}
flipped = {v: k for k, v in original.items()}
# {1: "a", 2: "b"}
```

### 常见错误

- ❌ `student["grade"]` — 键不存在时报 KeyError
- ✅ `student.get("grade", "N/A")` — 用 get 设默认值
- ❌ 用可变类型作字典键（如 list）
- ✅ 字典的键必须可哈希：str、int、tuple 可以，list、dict 不可以

### 小结

- dict = 键值对，键必须可哈希
- set = 无序不重复集合
- `get()` 安全访问字典
- 支持推导式和集合运算
