## 运算符与表达式

### 算术运算符

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `+` | 加法 | `5 + 3` | `8` |
| `-` | 减法 | `5 - 3` | `2` |
| `*` | 乘法 | `5 * 3` | `15` |
| `/` | 除法 | `5 / 2` | `2`（整数除法）|
| `%` | 取模（余数）| `5 % 2` | `1` |

### 整数除法陷阱

```java
int a = 5 / 2;        // a = 2，不是 2.5！
double b = 5 / 2;     // b = 2.0，先整数除法再转换
double c = 5.0 / 2;   // c = 2.5 ✅
```

### 关系运算符

`>` `<` `>=` `<=` `==` `!=` 返回 boolean 值。

```java
int a = 5, b = 3;
boolean result = a > b;  // true
```

### 逻辑运算符

```java
boolean x = true, y = false;
x && y  // false — 与（AND）
x || y  // true  — 或（OR）
!x      // false — 非（NOT）
```

`&&` 和 `||` 有短路特性：左边能确定结果时右边不执行。

### 赋值运算符

`+=` `-=` `*=` `/=` `%=` 是复合赋值。

```java
int x = 10;
x += 5;   // x = 15
```

### 自增自减

```java
int i = 5;
int a = i++;  // a=5, i=6（先赋值后加）
int b = ++i;  // b=7, i=7（先加后赋值）
```

### 常见错误

- ❌ `if (a = 5)` — 把赋值当比较
- ✅ `if (a == 5)` — 比较用双等号

### 小结

- 整数除法截断小数部分
- `==` 比较，`=` 赋值，不要混淆
- `&&` 和 `||` 有短路特性
- `i++` 先用后加，`++i` 先加后用
