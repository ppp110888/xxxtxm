# 第3章 Java 核心类库

> Java 提供了丰富的内置类库，掌握这些常用类能让你事半功倍。

## 本章目标

1. 掌握 String 类的常用方法
2. 理解 StringBuilder 的性能优势
3. 掌握包装类和自动装箱/拆箱
4. 使用 Math 和 Random 进行数学运算
5. 使用日期时间 API 处理时间
6. 掌握正则表达式的基本用法
7. 理解异常处理机制
