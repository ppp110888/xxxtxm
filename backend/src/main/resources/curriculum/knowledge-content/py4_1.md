## with 语句与上下文管理

### with 语句

`with` 语句确保资源在使用后被正确释放：

```python
# 不用 with — 需要手动关闭
f = open("data.txt", "r")
try:
    content = f.read()
finally:
    f.close()

# 用 with — 自动关闭
with open("data.txt", "r") as f:
    content = f.read()
# with 块结束后，f.close() 自动被调用
```

### 多个资源

```python
# 同时打开多个文件
with open("src.txt") as src, open("dst.txt", "w") as dst:
    dst.write(src.read().upper())
```

### 自定义上下文管理器

```python
class Timer:
    """计时器上下文管理器"""
    def __enter__(self):
        import time
        self.start = time.time()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        import time
        self.elapsed = time.time() - self.start
        print(f"耗时: {self.elapsed:.3f}秒")
        return False  # 不抑制异常

with Timer() as t:
    total = sum(range(10**7))
# 输出: 耗时: 0.234秒
```

### contextlib 模块

```python
from contextlib import contextmanager

@contextmanager
def timer():
    """用生成器创建上下文管理器"""
    import time
    start = time.time()
    yield  # 在 yield 处暂停
    elapsed = time.time() - start
    print(f"耗时: {elapsed:.3f}秒")

with timer():
    total = sum(range(10**7))

# 另一个例子：临时切换
@contextmanager
def temporary_value(obj, attr, temp_val):
    original = getattr(obj, attr)
    setattr(obj, attr, temp_val)
    try:
        yield
    finally:
        setattr(obj, attr, original)
```

### 常用上下文管理器

```python
# 文件操作
with open("data.txt") as f:
    ...

# 线程锁
import threading
lock = threading.Lock()
with lock:
    # 临界区
    ...

# 数据库连接 — 自动 commit/rollback
# with connection:
#     cursor.execute(...)
```

### 小结

- `with` 确保资源正确释放，替代 try-finally
- `__enter__` 进入时调用，`__exit__` 退出时调用
- `@contextmanager` 简化上下文管理器创建
- 适用于文件、锁、连接等需要清理的场景
