## Lambda 表达式

### 语法

```java
(参数列表) -> { 方法体 }
```

### 演进过程

```java
// 1. 传统匿名内部类
Runnable r1 = new Runnable() {
    @Override
    public void run() {
        System.out.println("Hello");
    }
};

// 2. Lambda 表达式
Runnable r2 = () -> {
    System.out.println("Hello");
};

// 3. 更简洁（单行可省略大括号）
Runnable r3 = () -> System.out.println("Hello");
```

### 各种形式

```java
// 无参数
() -> System.out.println("Hi");

// 一个参数（可省略括号）
x -> x * 2;

// 多个参数
(x, y) -> x + y;

// 多行方法体
(x, y) -> {
    int sum = x + y;
    return sum * 2;
};
```

### 使用场景

```java
List<String> names = Arrays.asList("张三", "李四", "王五");

// 排序
names.sort((a, b) -> a.compareTo(b));

// 遍历
names.forEach(name -> System.out.println(name));

// 过滤
names.removeIf(name -> name.startsWith("张"));

// 线程
new Thread(() -> System.out.println("运行")).start();
```

### 小结

- Lambda = 匿名函数的简写
- 语法：`(参数) -> { 方法体 }`
- 配合集合和线程使用非常方便
