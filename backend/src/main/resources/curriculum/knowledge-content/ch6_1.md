## 线程概念与生命周期

### 进程 vs 线程

| 概念 | 说明 | 类比 |
|------|------|------|
| **进程** | 操作系统分配资源的最小单位 | 一个独立运行的程序 |
| **线程** | CPU 调度的最小单位 | 程序中的一条执行路径 |

一个进程可以有多个线程，线程共享进程的内存空间。

### 线程生命周期

```
NEW(新建) → RUNNABLE(可运行) → BLOCKED(阻塞)
                   ↓              ↓
               WAITING(等待)  TIMED_WAITING(计时等待)
                   ↓              ↓
              TERMINATED(终止)
```

### 主线程

```java
public class Main {
    public static void main(String[] args) {
        // main 方法运行在主线程
        Thread current = Thread.currentThread();
        System.out.println(current.getName());  // "main"
    }
}
```

### 小结

- 进程包含线程，线程共享进程资源
- Java 程序至少有一个主线程
- 线程状态：NEW → RUNNABLE → ... → TERMINATED
