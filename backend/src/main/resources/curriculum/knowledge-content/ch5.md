# 第5章 IO 流

> IO（Input/Output）流用于读写文件、网络传输等数据交换场景。

## 本章目标

1. 使用 File 类操作文件和目录
2. 理解字节流与字符流的区别
3. 掌握缓冲流提升读写性能
4. 了解对象序列化

## 章节导航

| 节 | 内容 | 关键类 |
|----|------|--------|
| 5.1 | File 类基础 | 创建/删除/判断/列出文件 |
| 5.2 | 字节流 | InputStream / OutputStream / FileInputStream |
| 5.3 | 字符流 | Reader / Writer / FileReader / FileWriter |
| 5.4 | 缓冲流 | BufferedReader / BufferedWriter / BufferedInputStream |
| 5.5 | 对象序列化 | Serializable / ObjectOutputStream / ObjectInputStream |
