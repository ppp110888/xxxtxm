## 数组

### 数组声明与初始化

```java
// 方式1：声明 + 分配空间
int[] scores = new int[5];  // 5个元素，默认值为0

// 方式2：声明 + 初始化
int[] numbers = {10, 20, 30, 40, 50};

// 方式3：先声明再分配
int[] arr;
arr = new int[]{1, 2, 3};
```

### 访问数组元素

```java
int[] nums = {10, 20, 30, 40, 50};

int first = nums[0];    // 第一个元素：10（索引从0开始）
int last = nums[4];     // 最后一个元素：50

nums[2] = 99;           // 修改第三个元素

int length = nums.length; // 数组长度：5
```

### 遍历数组

```java
// 方式1：普通 for 循环
for (int i = 0; i < nums.length; i++) {
    System.out.println(nums[i]);
}

// 方式2：增强 for-each 循环（推荐）
for (int num : nums) {
    System.out.println(num);
}
```

### 二维数组

```java
// 声明3行4列的二维数组
int[][] matrix = new int[3][4];

// 初始化
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// 遍历
for (int i = 0; i < grid.length; i++) {
    for (int j = 0; j < grid[i].length; j++) {
        System.out.print(grid[i][j] + " ");
    }
    System.out.println();
}
```

### 常见错误

- ❌ `int[] arr = new int[3]; arr[3] = 10;` — 索引3越界（有效索引 0-2）
- ✅ 最大索引是 `长度-1`

- ❌ `int[] arr; arr = {1, 2, 3};` — 简写语法只能在声明时使用
- ✅ `arr = new int[]{1, 2, 3};` — 重新赋值用 new

### 小结

- 数组是**固定长度**的同类数据容器
- 索引从 **0** 开始
- `length` 属性获取长度
- 增强 for-each 遍历更简洁安全
- 访问越界会抛出 `ArrayIndexOutOfBoundsException`
