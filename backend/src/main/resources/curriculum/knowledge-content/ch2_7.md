## 多态

### 多态的本质

**父类引用指向子类对象**，同一个方法在不同对象上表现出不同行为。

```java
Animal a1 = new Dog();   // 父类引用 → 子类对象
Animal a2 = new Cat();   // 父类引用 → 子类对象

a1.makeSound();  // "汪汪汪" — 调用 Dog 的方法
a2.makeSound();  // "喵喵喵" — 调用 Cat 的方法
// 同一个 makeSound()，不同的表现 → 多态！
```

### 实际应用

```java
// 不用多态：每种动物单独处理
public void playSound(Dog dog) { dog.makeSound(); }
public void playSound(Cat cat) { cat.makeSound(); }

// 用多态：统一处理所有动物
public void playSound(Animal animal) {
    animal.makeSound();  // 实际执行哪个方法由对象决定
}
```

### instanceof 判断类型

```java
Animal a = new Dog();

if (a instanceof Dog) {
    Dog d = (Dog) a;  // 向下转型（需要强制转换）
    d.wagTail();       // 调用 Dog 特有方法
}
```

### 多态的条件

1. 有继承/实现关系
2. 子类重写父类方法
3. 父类引用指向子类对象

### 常见错误

- ❌ `Dog d = new Animal();` — 不能把父类对象赋给子类引用（编译错误）
- ✅ `Animal a = new Dog();` — 父类引用可以指向子类对象

### 小结

- 多态 = 父类引用 + 子类对象 + 方法重写
- 编译看左边（父类），运行看右边（子类）
- `instanceof` 判断实际类型
- 多态是 OOP 最强大的特性
