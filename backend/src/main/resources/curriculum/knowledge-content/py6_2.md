## 线程安全与 Lock

### 线程安全问题

```python
import threading

# ❌ 非线程安全
counter = 0

def increment():
    global counter
    for _ in range(100000):
        counter += 1  # 这不是原子操作！

threads = [threading.Thread(target=increment) for _ in range(4)]
for t in threads: t.start()
for t in threads: t.join()

print(counter)  # 结果不确定！可能小于 400000
```

### Lock — 互斥锁

```python
import threading

counter = 0
lock = threading.Lock()

def safe_increment():
    global counter
    for _ in range(100000):
        with lock:           # 上下文管理器自动 acquire/release
            counter += 1

threads = [threading.Thread(target=safe_increment) for _ in range(4)]
for t in threads: t.start()
for t in threads: t.join()

print(counter)  # 400000 ✅ 正确！
```

### Lock 基本用法

```python
lock = threading.Lock()

# 方式1: 上下文管理器（推荐）
with lock:
    # 临界区代码
    pass

# 方式2: 手动 acquire/release
lock.acquire()
try:
    # 临界区代码
    pass
finally:
    lock.release()  # 一定在 finally 中释放！
```

### RLock — 可重入锁

```python
# RLock 允许同一线程多次获取同一个锁
rlock = threading.RLock()

def recursive_func(n):
    with rlock:
        if n > 0:
            print(f"深度: {n}")
            recursive_func(n - 1)  # 同一线程可再次获取

recursive_func(3)  # ✅ Lock 会死锁，RLock 不会
```

### Semaphore — 信号量

```python
# 限制同时访问资源的线程数
semaphore = threading.Semaphore(2)  # 最多2个线程同时执行

shared_resource = []

def limited_access(name):
    with semaphore:
        print(f"{name} 获取信号量")
        shared_resource.append(name)
        import time
        time.sleep(0.5)
        print(f"{name} 释放信号量")

threads = [threading.Thread(target=limited_access, args=(f"T{i}",)) for i in range(5)]
for t in threads: t.start()
for t in threads: t.join()
```

### 死锁

```python
# ⚠️ 死锁示例（不要这样写！）
lock_a = threading.Lock()
lock_b = threading.Lock()

def task1():
    with lock_a:
        time.sleep(0.1)
        with lock_b:  # 等 lock_b
            pass

def task2():
    with lock_b:
        time.sleep(0.1)
        with lock_a:  # 等 lock_a → 死锁！
            pass
```

### 小结

- 多个线程修改共享数据需加锁
- `Lock` 互斥锁，`with lock:` 推荐用法
- `RLock` 可重入，`Semaphore` 限流
- 避免死锁：统一加锁顺序，使用超时 `lock.acquire(timeout=...)`
