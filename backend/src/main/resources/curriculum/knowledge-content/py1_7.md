## 函数定义与调用

### 定义函数

```python
# 基本语法
def greet(name):
    """向指定的人打招呼"""  # 文档字符串
    return f"你好，{name}！"

# 调用
print(greet("小明"))  # 你好，小明！
```

### 参数类型

```python
# 1. 位置参数
def add(a, b):
    return a + b

# 2. 默认参数（必须放在位置参数后面）
def greet(name, greeting="你好"):
    return f"{greeting}，{name}！"

print(greet("小明"))           # 你好，小明！
print(greet("Tom", "Hello"))   # Hello，Tom！

# 3. 可变参数 *args — 接收任意多位置参数
def sum_all(*args):
    return sum(args)

print(sum_all(1, 2, 3, 4))  # 10

# 4. 关键字参数 **kwargs — 接收任意多命名参数
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="小明", age=18)
```

### 返回值

```python
# 返回单个值
def square(x):
    return x ** 2

# 返回多个值（实际是返回元组）
def min_max(nums):
    return min(nums), max(nums)

a, b = min_max([3, 1, 4, 1, 5])  # a=1, b=5

# 无返回值 — 默认返回 None
def say_hello():
    print("Hello")

result = say_hello()  # result 是 None
```

### 变量作用域

```python
x = 10  # 全局变量

def func():
    y = 20  # 局部变量
    global x  # 声明使用全局变量
    x = 30

func()
print(x)  # 30
# print(y)  # 错误！局部变量在函数外不可访问
```

### Lambda 匿名函数

```python
# 语法：lambda 参数: 表达式
square = lambda x: x ** 2
print(square(5))  # 25

# 常用于排序 key
students = [("小明", 85), ("小红", 92)]
students.sort(key=lambda s: s[1])  # 按分数排序
```

### 常见错误

- ❌ 默认参数用可变对象 `def f(lst=[])`
- ✅ `def f(lst=None): if lst is None: lst = []`
- ❌ 忘记 `return` 语句
- ❌ 参数顺序错：`def f(a=1, b)` — 默认参数在后

### 小结

- `def` 定义函数，`return` 返回值
- 支持默认参数、可变参数、关键字参数
- 函数内部变量是局部变量
- `lambda` 用于简短匿名函数
