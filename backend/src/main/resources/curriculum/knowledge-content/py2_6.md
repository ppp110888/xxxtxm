## 魔术方法

### 什么是魔术方法？

魔术方法（Magic Methods）是 Python 中以双下划线 `__xxx__` 开头和结尾的特殊方法，也叫 Dunder Methods。它们让自定义类支持内置操作。

### 常用魔术方法

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        """开发者友好表示"""
        return f"Vector({self.x}, {self.y})"

    def __str__(self):
        """用户友好表示"""
        return f"({self.x}, {self.y})"

    def __eq__(self, other):
        """等于 == """
        return self.x == other.x and self.y == other.y

    def __add__(self, other):
        """加法 + """
        return Vector(self.x + other.x, self.y + other.y)

    def __len__(self):
        """len() """
        return 2

    def __abs__(self):
        """abs() — 向量长度"""
        return (self.x**2 + self.y**2) ** 0.5

    def __bool__(self):
        """bool() — 非零向量为 True"""
        return self.x != 0 or self.y != 0

v1 = Vector(3, 4)
v2 = Vector(3, 4)
print(v1)           # (3, 4)
print(repr(v1))     # Vector(3, 4)
print(v1 == v2)     # True
print(v1 + v2)      # (6, 8)
print(len(v1))      # 2
print(abs(v1))      # 5.0
```

### 容器类魔术方法

```python
class Playlist:
    def __init__(self):
        self._songs = []

    def __getitem__(self, index):
        """索引访问 playlist[i]"""
        return self._songs[index]

    def __setitem__(self, index, value):
        """索引赋值 playlist[i] = song"""
        self._songs[index] = value

    def __len__(self):
        """len(playlist)"""
        return len(self._songs)

    def __contains__(self, item):
        """item in playlist"""
        return item in self._songs

    def __iter__(self):
        """for song in playlist"""
        return iter(self._songs)

    def add(self, song):
        self._songs.append(song)
```

### 上下文管理

```python
class File:
    def __init__(self, filename, mode):
        self.filename = filename
        self.mode = mode

    def __enter__(self):
        print(f"打开 {self.filename}")
        self._handle = open(self.filename, self.mode)
        return self._handle

    def __exit__(self, exc_type, exc_val, exc_tb):
        print(f"关闭 {self.filename}")
        self._handle.close()
        return False  # 不抑制异常

with File("test.txt", "w") as f:
    f.write("Hello")
```

### 常见魔术方法速查

| 方法 | 触发 |
|------|------|
| `__init__` | 创建对象 |
| `__str__` | `print()` / `str()` |
| `__repr__` | `repr()` / 交互环境 |
| `__eq__` / `__lt__` | `==` / `<` |
| `__add__` / `__sub__` | `+` / `-` |
| `__len__` | `len()` |
| `__getitem__` | `obj[key]` |
| `__iter__` / `__next__` | `for` 循环 |
| `__enter__` / `__exit__` | `with` 语句 |

### 小结

- 魔术方法让自定义类支持 Python 内置操作
- 常用的：`__init__`, `__str__`, `__repr__`, `__eq__`, `__add__`
- `__getitem__` 实现索引访问
- `__enter__`/`__exit__` 实现上下文管理器
