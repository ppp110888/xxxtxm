## 类与对象

### 定义类

```python
class Person:
    """人员类"""

    species = "人类"  # 类属性

    def __init__(self, name, age):
        """初始化方法"""
        self.name = name  # 实例属性
        self.age = age

    def greet(self):
        """实例方法"""
        return f"我是{self.name}，今年{self.age}岁"

# 创建对象
p1 = Person("小明", 18)
p2 = Person("小红", 20)

print(p1.greet())  # 我是小明，今年18岁
print(p2.greet())  # 我是小红，今年20岁
```

### self 是什么？

`self` 代表**实例本身**。方法调用时，Python 自动把实例作为第一个参数传入。

```python
class Demo:
    def show(self):
        print(f"self={self}, type={type(self)}")

d = Demo()
d.show()
# self=<__main__.Demo object at 0x...>, type=<class '__main__.Demo'>
```

### 类属性 vs 实例属性

```python
class Student:
    school = "第一中学"  # 类属性 — 所有实例共享

    def __init__(self, name):
        self.name = name  # 实例属性 — 每个实例独立

s1 = Student("小明")
s2 = Student("小红")

print(s1.school)  # 第一中学
print(s2.school)  # 第一中学
Student.school = "第二中学"  # 修改类属性，所有实例可见
print(s1.school)  # 第二中学
print(s2.school)  # 第二中学
```

### 实例方法 vs 静态方法 vs 类方法

```python
class MyClass:
    # 实例方法 — 访问实例属性
    def instance_method(self):
        return f"实例方法, self={self}"

    # 类方法 — 访问类属性
    @classmethod
    def class_method(cls):
        return f"类方法, cls={cls}"

    # 静态方法 — 不需要 self 或 cls
    @staticmethod
    def static_method():
        return "静态方法, 不需要实例"
```

### 小结

- `class` 定义类，`self` 代表实例本身
- `__init__` 是初始化方法，创建对象时自动调用
- 类属性所有实例共享，实例属性各自独立
- `@classmethod` 和 `@staticmethod` 用于不同场景
