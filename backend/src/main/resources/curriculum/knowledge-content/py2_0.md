## 面向对象思想概述

### 什么是面向对象？

**面向对象编程（OOP）** 是一种以**对象**为核心的编程范式。对象 = 数据 + 行为。

### 类比理解

想象你在制造一辆汽车：
- **类（class）** = 设计图纸
- **对象（object）** = 按图纸造出来的实体车
- **属性（attribute）** = 车的颜色、速度、油量
- **方法（method）** = 车能做的事：加速、刹车、转向

### 面向对象 vs 面向过程

```python
# 面向过程
def calc_area(width, height):
    return width * height

# 面向对象
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

rect = Rectangle(4, 5)
print(rect.area())  # 20
```

### 三大特性

| 特性 | 含义 | Python 实现 |
|------|------|-------------|
| **封装** | 隐藏内部细节，暴露接口 | 私有属性 + property |
| **继承** | 子类复用父类代码 | `class Child(Parent):` |
| **多态** | 同一接口，不同行为 | 鸭子类型 + 方法重写 |

### 核心概念

```python
class Dog:
    species = "犬科"  # 类属性（所有实例共享）

    def __init__(self, name):
        self.name = name  # 实例属性（每个实例不同）

    def bark(self):       # 方法
        print(f"{self.name}汪汪叫！")

# 创建对象
my_dog = Dog("旺财")
my_dog.bark()  # 旺财汪汪叫！
```

### Python 中一切皆对象

```python
print(type(5))        # <class 'int'>
print(type("hi"))     # <class 'str'>
print(type(Dog))      # <class 'type'>
print(type(my_dog))   # <class '__main__.Dog'>
```

### 小结

- OOP 以对象为核心，对象 = 数据 + 行为
- 类 是蓝图，对象 是实例
- 三大特性：封装、继承、多态
- Python 中一切皆对象
