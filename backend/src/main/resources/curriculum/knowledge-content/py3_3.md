## 迭代器与生成器

### 可迭代对象 vs 迭代器

```python
# 可迭代对象 (Iterable) — 能放进 for 循环
nums = [1, 2, 3]  # list 是可迭代对象
s = "hello"       # str 是可迭代对象

# 迭代器 (Iterator) — 能被 next() 调用
it = iter(nums)    # 从可迭代对象获取迭代器
print(next(it))    # 1
print(next(it))    # 2
print(next(it))    # 3
# next(it)         # StopIteration
```

### 自定义迭代器

```python
class Countdown:
    """倒计时迭代器"""
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.current < 0:
            raise StopIteration
        value = self.current
        self.current -= 1
        return value

for n in Countdown(3):
    print(n)  # 3, 2, 1, 0
```

### 生成器 — yield

生成器是创建迭代器的最简单方式：

```python
# 生成器函数
def countdown(start):
    while start >= 0:
        yield start
        start -= 1

for n in countdown(3):
    print(n)  # 3, 2, 1, 0

# 无限生成器
def infinite_counter():
    n = 0
    while True:
        yield n
        n += 1

gen = infinite_counter()
print(next(gen))  # 0
print(next(gen))  # 1
```

### yield from — 委托子生成器

```python
def flatten(nested_list):
    """展平嵌套列表"""
    for sublist in nested_list:
        yield from sublist  # 委托给子列表的迭代器

result = list(flatten([[1, 2], [3, 4], [5]]))
print(result)  # [1, 2, 3, 4, 5]
```

### 生成器的优势

| 场景 | 列表 | 生成器 |
|------|------|--------|
| 内存 | 一次性加载 | 按需生成 |
| 速度 | 首次快 | 每次省内存 |
| 无限序列 | ❌ 不可能 | ✅ 支持 |
| 复用 | ✅ 可重复 | ❌ 一次性 |

```python
# 大文件处理 — 生成器省内存
def read_large_file(filepath):
    with open(filepath) as f:
        for line in f:      # f 本身就是迭代器
            yield line.strip()
```

### 常见错误

- ❌ 把生成器当成列表重复遍历
- ✅ 生成器只能迭代一次，需要时转为 list
- ❌ `return` vs `yield` 混淆

### 小结

- 可迭代对象实现 `__iter__`，迭代器实现 `__next__`
- `yield` 是创建生成器的最简单方式
- 生成器惰性求值，适合大数据处理
- `yield from` 委托子生成器
