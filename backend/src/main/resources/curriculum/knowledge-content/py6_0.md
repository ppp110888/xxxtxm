## 线程概念与 GIL

### 并发 vs 并行

| 概念 | 含义 |
|------|------|
| **并发 Concurrency** | 多任务交替执行（单核也能并发） |
| **并行 Parallelism** | 多任务同时执行（需要多核） |

### Python 的 GIL

**GIL (Global Interpreter Lock)** 是 CPython 解释器的一个互斥锁。它保证同一时刻只有一个线程执行 Python 字节码。

```python
# GIL 的影响：
# ✅ IO 密集型任务 — 多线程有效（线程在等IO时释放GIL）
# ❌ CPU 密集型任务 — 多线程无效（甚至更慢！）
#    → 改用 multiprocessing 多进程
```

### 线程 vs 进程

| | 线程 Thread | 进程 Process |
|------|-------------|--------------|
| 内存 | 共享 | 独立 |
| 通信 | 简单（共享变量） | 需要 IPC |
| 开销 | 轻量 | 重量 |
| GIL | 受限制 | 不受限制 |
| 适用 | IO 密集型 | CPU 密集型 |

### 简单线程示例

```python
import threading
import time

def worker(name, delay):
    for i in range(3):
        print(f"{name} 工作中... 第{i+1}次")
        time.sleep(delay)

# 创建线程
t1 = threading.Thread(target=worker, args=("线程A", 0.5))
t2 = threading.Thread(target=worker, args=("线程B", 0.3))

# 启动
t1.start()
t2.start()

# 等待完成
t1.join()
t2.join()

print("所有线程完成")
```

### 线程生命周期

```
新建 → 就绪 → 运行 → 死亡
              ↑    ↓
              阻塞态
```

### 小结

- GIL 限制 CPython 多线程并行执行 Python 字节码
- IO 密集用多线程，CPU 密集用多进程
- `threading.Thread(target=func, args=(...))` 创建线程
- `start()` 启动，`join()` 等待
