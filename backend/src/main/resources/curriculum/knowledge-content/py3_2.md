## 推导式

### 列表推导式

```python
# 基本形式
squares = [x**2 for x in range(10)]
# [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# 带条件
evens = [x for x in range(10) if x % 2 == 0]
# [0, 2, 4, 6, 8]

# if-else
labels = ["偶数" if x % 2 == 0 else "奇数" for x in range(5)]
# ["偶数", "奇数", "偶数", "奇数", "偶数"]

# 嵌套循环
pairs = [(x, y) for x in "AB" for y in "12"]
# [("A", "1"), ("A", "2"), ("B", "1"), ("B", "2")]
```

### 字典推导式

```python
# 键值映射
squares = {x: x**2 for x in range(5)}
# {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 过滤字典
scores = {"小明": 85, "小红": 92, "小刚": 78}
passed = {k: v for k, v in scores.items() if v >= 80}
# {"小明": 85, "小红": 92}

# 反转键值
d = {"a": 1, "b": 2}
flipped = {v: k for k, v in d.items()}
# {1: "a", 2: "b"}
```

### 集合推导式

```python
unique_lengths = {len(word) for word in ["hello", "world", "python"]}
# {5, 6}

# 去重
items = [1, 2, 2, 3, 3, 3]
unique = {x for x in items}
# {1, 2, 3}
```

### 生成器表达式

```python
# 使用 () 而非 [] — 惰性求值，节省内存
squares_gen = (x**2 for x in range(10**6))
print(next(squares_gen))  # 0
print(next(squares_gen))  # 1

# 适用场景：大文件处理
lines = (line.strip() for line in open("big_file.txt"))
```

### 对比

| 类型 | 符号 | 特点 |
|------|------|------|
| 列表推导式 | `[...]` | 立即计算，生成 list |
| 字典推导式 | `{k:v ...}` | 立即计算，生成 dict |
| 集合推导式 | `{...}` | 立即计算，生成 set |
| 生成器表达式 | `(...)` | 惰性求值，节省内存 |

### 小结

- 推导式 = 简洁优雅的数据转换方式
- 列表推导 `[expr for x in iterable if cond]`
- 字典推导 `{k: v for ...}`
- 生成器表达式用 `()`，惰性求值
- 不要写过于复杂的推导式（可读性优先）
