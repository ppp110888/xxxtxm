## File 类基础

```java
import java.io.File;
import java.io.IOException;

// 创建 File 对象
File file = new File("D:/test/hello.txt");
File dir = new File("D:/test");

// 文件和目录操作
boolean created = file.createNewFile();  // 创建文件
boolean mkdir = dir.mkdirs();            // 创建多级目录
boolean deleted = file.delete();         // 删除（不进回收站）
boolean exists = file.exists();          // 是否存在
boolean isFile = file.isFile();          // 是文件？
boolean isDir  = file.isDirectory();     // 是目录？

// 获取信息
String name = file.getName();           // "hello.txt"
long length = file.length();            // 字节数
String[] list = dir.list();             // 列出内容

// 遍历目录中的文件
for (File f : dir.listFiles()) {
    System.out.println(f.getName());
}
```

### 小结

- File 代表文件或目录的路径
- 不保证文件真实存在，需 `exists()` 检查
