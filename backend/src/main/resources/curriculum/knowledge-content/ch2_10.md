## 内部类基础

### 内部类的类型

```java
public class Outer {
    // 1. 成员内部类
    class Inner {
        void print() { System.out.println("成员内部类"); }
    }

    // 2. 静态内部类
    static class StaticInner {
        void print() { System.out.println("静态内部类"); }
    }

    public void method() {
        // 3. 局部内部类
        class LocalInner {
            void print() { System.out.println("局部内部类"); }
        }
        new LocalInner().print();
    }
}
```

### 匿名内部类（最常用）

```java
// 不用匿名内部类：需要单独定义类
MyListener listener = new MyListener();

// 用匿名内部类：一行搞定
Runnable task = new Runnable() {
    @Override
    public void run() {
        System.out.println("运行中...");
    }
};
new Thread(task).start();
```

### 使用场景

- **匿名内部类**：事件处理、回调、简单接口实现
- **静态内部类**：与外部类强相关但不需要访问外部实例
- **成员内部类**：需要访问外部类成员时

### 小结

- 内部类可以访问外部类的私有成员
- 匿名内部类是最常用的内部类形式
- Lambda 表达式可以替代单方法接口的匿名内部类
