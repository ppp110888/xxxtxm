## 字符串详解

### 字符串创建

```python
s1 = "hello"
s2 = 'hello'
s3 = """多行
字符串"""
s4 = 'I\'m fine'  # 转义
s5 = r'C:\new\test'  # 原始字符串
```

### 字符串索引与切片

```python
s = "Hello, Python"

# 索引
print(s[0])    # H
print(s[-1])   # n
print(s[7])    # P

# 切片
print(s[0:5])   # Hello
print(s[7:])    # Python
print(s[:5])    # Hello
print(s[::-1])  # nohtyP ,olleH — 反转
```

### 常用方法

```python
s = "Hello, World"

s.upper()          # "HELLO, WORLD"
s.lower()          # "hello, world"
s.title()          # "Hello, World"
s.strip()          # 去首尾空白
s.replace("World", "Python")  # "Hello, Python"
s.split(", ")      # ["Hello", "World"]
", ".join(["a", "b", "c"])  # "a, b, c"
"Hello, World".startswith("Hello")  # True
"Hello, World".endswith("World")    # True
"hello".capitalize()  # "Hello"

# 查找
s.find("World")     # 7 (找不到返回-1)
s.index("World")    # 7 (找不到抛异常)
"Hello" in s        # True
s.count("l")        # 3

# 判断
"123".isdigit()     # True
"abc".isalpha()     # True
"abc123".isalnum()  # True
"  ".isspace()      # True
```

### f-string 格式化

```python
name = "小明"
age = 18
score = 95.5

print(f"我叫{name}，今年{age}岁")
print(f"分数: {score:.1f}")       # 95.5
print(f"百分比: {0.856:.1%}")     # 85.6%
print(f"{age:>5d}")               # "   18" 右对齐
print(f"{name:*^10}")             # "***小明****" 居中对齐
```

### 字符串不可变

```python
s = "hello"
# s[0] = 'H'  # TypeError! 字符串不可修改
s = "H" + s[1:]  # "Hello" — 创建新字符串
```

### 小结

- 字符串支持索引、切片、不可变
- f-string 是最高效的格式化方式
- `split()` 拆分为列表，`join()` 合并为字符串
- `r'...'` 原始字符串忽略转义
