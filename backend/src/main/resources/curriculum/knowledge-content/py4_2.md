## CSV 与 JSON 处理

### CSV 读取

```python
import csv

# 基础读取
with open("data.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)  # ["name", "age", "score"]

# DictReader — 每行是字典
with open("data.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        print(row["name"], row["age"])
```

### CSV 写入

```python
# 基础写入
with open("output.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "age", "score"])
    writer.writerow(["小明", 18, 95])

# DictWriter
with open("output.csv", "w", newline="", encoding="utf-8") as f:
    fieldnames = ["name", "age", "score"]
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerow({"name": "小明", "age": 18, "score": 95})
```

### JSON 处理

```python
import json

# Python → JSON (序列化)
data = {
    "name": "小明",
    "age": 18,
    "scores": [85, 92, 78]
}
json_str = json.dumps(data, ensure_ascii=False, indent=2)
print(json_str)

# 写入文件
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)

# JSON → Python (反序列化)
json_str = '{"name": "小明", "age": 18}'
obj = json.loads(json_str)
print(obj["name"])  # 小明

# 读取文件
with open("data.json", "r", encoding="utf-8") as f:
    obj = json.load(f)
```

### JSON 自定义序列化

```python
import json
from datetime import datetime

# 自定义编码器
class DateTimeEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, datetime):
            return obj.isoformat()
        return super().default(obj)

data = {"time": datetime.now()}
json_str = json.dumps(data, cls=DateTimeEncoder)

# 更简单的方案
def default_handler(obj):
    if isinstance(obj, datetime):
        return obj.isoformat()
    raise TypeError(f"无法序列化 {type(obj)}")

json_str = json.dumps(data, default=default_handler)
```

### 常见错误

- ❌ CSV 写入有空行 — 忘记 `newline=""`
- ✅ `open("f.csv", "w", newline="")`
- ❌ JSON 中文变 `\uXXXX` — 忘记 `ensure_ascii=False`
- ✅ `json.dumps(data, ensure_ascii=False)`

### 小结

- `csv.reader` 读 CSV，`csv.writer` 写 CSV
- `DictReader`/`DictWriter` 用字典操作
- `json.dumps`/`json.loads` 处理 JSON
- 中文 JSON 用 `ensure_ascii=False`
