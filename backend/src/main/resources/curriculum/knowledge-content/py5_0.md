## collections 模块

### Counter — 计数器

```python
from collections import Counter

# 统计频率
words = ["a", "b", "a", "c", "b", "a"]
cnt = Counter(words)
print(cnt)  # Counter({"a": 3, "b": 2, "c": 1})

# 常用操作
cnt.most_common(2)   # [("a", 3), ("b", 2)]  前 2 名
cnt["a"]             # 3 — 访问计数
cnt["x"]             # 0 — 不存在的键返回 0（不报错!）
cnt.total()          # 6 — 总计数

# 运算
c1 = Counter(a=3, b=2)
c2 = Counter(a=1, b=3, c=2)
c1 + c2    # Counter({"a": 4, "b": 5, "c": 2})
c1 - c2    # Counter({"a": 2}) — 负值丢弃
```

### defaultdict — 带默认值的字典

```python
from collections import defaultdict

# 用 int 作默认工厂
counts = defaultdict(int)
words = ["a", "b", "a"]
for w in words:
    counts[w] += 1      # 不存在时自动初始化为 0
print(counts)  # {"a": 2, "b": 1}

# 用 list 作默认工厂
groups = defaultdict(list)
students = [("A班", "小明"), ("B班", "小红"), ("A班", "小刚")]
for cls, name in students:
    groups[cls].append(name)
print(groups)  # {"A班": ["小明", "小刚"], "B班": ["小红"]}
```

### OrderedDict — 有序字典

Python 3.7+ 的 dict 已保证插入顺序，OrderedDict 主要用于：
- `move_to_end()` 方法
- 相等比较时考虑顺序

```python
from collections import OrderedDict

d = OrderedDict()
d["a"] = 1
d["b"] = 2
d["c"] = 3
d.move_to_end("a")  # 移到末尾
print(d)  # OrderedDict([("b", 2), ("c", 3), ("a", 1)])
```

### namedtuple — 命名元组

```python
from collections import namedtuple

# 定义
Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)

print(p.x)     # 3 — 通过名字访问
print(p[0])    # 3 — 也支持索引
print(p)       # Point(x=3, y=4)
# p.x = 5      # AttributeError — 不可变
```

### deque — 双端队列

```python
from collections import deque

q = deque([1, 2, 3])
q.append(4)         # 右侧添加
q.appendleft(0)     # 左侧添加
q.pop()             # 右侧弹出
q.popleft()         # 左侧弹出
print(q)            # deque([1, 2, 3])

# 固定大小（满时自动丢弃旧元素）
dq = deque(maxlen=3)
dq.extend([1, 2, 3, 4, 5])
print(dq)  # deque([3, 4, 5], maxlen=3)
```

### 小结

- `Counter` — 计数神器
- `defaultdict` — 不用检查键是否存在
- `namedtuple` — 轻量级数据类
- `deque` — O(1) 首尾操作
