## 异常处理

### try-except

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("除数不能为零")
```

### 捕获多种异常

```python
try:
    num = int(input("输入一个数字: "))
    result = 100 / num
except ValueError:
    print("请输入有效的数字")
except ZeroDivisionError:
    print("数字不能为0")
except Exception as e:
    print(f"未知错误: {e}")
```

### else 和 finally

```python
try:
    file = open("data.txt")
    content = file.read()
except FileNotFoundError:
    print("文件不存在")
else:
    # 没有异常时执行
    print(f"读取了 {len(content)} 字节")
finally:
    # 无论如何都执行
    file.close()
    print("文件已关闭")
```

### 自定义异常

```python
class InvalidScoreError(Exception):
    """无效分数异常"""
    def __init__(self, score):
        self.score = score
        super().__init__(f"分数 {score} 不合法，应在0-100之间")

def set_score(score):
    if not 0 <= score <= 100:
        raise InvalidScoreError(score)
    print(f"分数设置为 {score}")

try:
    set_score(150)
except InvalidScoreError as e:
    print(e)  # 分数 150 不合法，应在0-100之间
```

### raise — 抛出异常

```python
def divide(a, b):
    if b == 0:
        raise ValueError("除数不能为0")
    return a / b

# 重新抛出
try:
    result = divide(10, 0)
except ValueError:
    print("处理中...")
    raise  # 重新抛出原异常
```

### 常见内建异常

| 异常 | 原因 |
|------|------|
| `ValueError` | 值不合法 |
| `TypeError` | 类型错误 |
| `KeyError` | 字典键不存在 |
| `IndexError` | 列表索引越界 |
| `FileNotFoundError` | 文件不存在 |
| `ZeroDivisionError` | 除数为零 |
| `AttributeError` | 属性不存在 |

### 小结

- `try-except-else-finally` 完整链路
- 捕获具体异常，不要裸用 `except:`
- `raise` 抛出异常或重新抛出
- 自定义异常继承 `Exception`
- `finally` 用于资源清理
