## 异常处理

### 异常体系

```
Throwable
├── Error（严重错误，不处理）
│   └── OutOfMemoryError / StackOverflowError
└── Exception
    ├── RuntimeException（运行时异常，可修复）
    │   └── NullPointerException / IndexOutOfBoundsException
    └── 非运行时异常（编译期异常，必须处理）
        └── IOException / SQLException
```

### try-catch-finally

```java
try {
    int result = 10 / 0;  // 可能抛出异常的代码
} catch (ArithmeticException e) {
    System.out.println("数学错误：" + e.getMessage());
} catch (Exception e) {
    System.out.println("其他异常：" + e.getMessage());
} finally {
    System.out.println("无论如何都会执行");  // 清理资源
}
```

### try-with-resources (Java 7+)

自动关闭资源，无需 finally：

```java
// 自动关闭 BufferedReader
try (BufferedReader reader = new BufferedReader(new FileReader("file.txt"))) {
    String line = reader.readLine();
    System.out.println(line);
} catch (IOException e) {
    e.printStackTrace();
}
// reader 自动关闭，无需手动 finally
```

### throws 声明

```java
// 声明该方法可能抛出异常，由调用者处理
public static void readFile(String path) throws IOException {
    Files.readString(Path.of(path));
}
```

### 自定义异常

```java
// 继承 Exception（编译期异常）或 RuntimeException（运行时异常）
public class InsufficientBalanceException extends Exception {
    public InsufficientBalanceException(String message) {
        super(message);
    }
}

// 使用
public void withdraw(double amount) throws InsufficientBalanceException {
    if (amount > balance) {
        throw new InsufficientBalanceException("余额不足");
    }
}
```

### 常见错误

- ❌ 空 catch 块吞掉异常：`catch (Exception e) { }`
- ✅ 至少打印日志：`e.printStackTrace()` 或用 log 记录

- ❌ finally 中使用 return（会覆盖 try 中的返回值）
- ✅ finally 只做资源清理，不在其中 return

### 小结

- try-catch 捕获处理异常
- finally 用于资源清理
- try-with-resources 自动关闭资源
- throws 声明异常，throw 抛出异常
- 不要吞掉异常
