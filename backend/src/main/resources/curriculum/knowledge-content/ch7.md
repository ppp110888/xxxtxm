# 第7章 Java 8+ 新特性

> Java 8 是 Java 历史上最大的版本升级之一。Lambda 和 Stream 改变了 Java 的编程风格。

## 本章目标

1. 掌握 Lambda 表达式的语法和使用场景
2. 使用 Stream API 进行函数式数据处理
3. 使用 Optional 优雅处理 null
4. 理解方法引用的四种形式
5. 了解常用的函数式接口

## 章节导航

| 节 | 内容 | 核心概念 |
|----|------|----------|
| 7.1 | Lambda 表达式 | 匿名函数 / 参数 / 箭头 / 体 |
| 7.2 | Stream API | 流式操作 / map/filter/reduce/collect |
| 7.3 | Optional | 优雅处理 null / orElse / ifPresent |
| 7.4 | 方法引用 | :: 语法 / 四种引用方式 |
| 7.5 | 函数式接口 | @FunctionalInterface / Predicate / Function / Consumer |
