## 线程安全与 synchronized

### 线程不安全演示

```java
// 共享变量，多线程同时修改 → 结果不确定！
int count = 0;

// 线程1: count++ (读→加1→写)
// 线程2: count++ (读→加1→写)
// 两个线程可能读到相同的值，导致少加一次
```

### synchronized 解决

```java
// 方式1：同步方法
public synchronized void increment() {
    count++;
}

// 方式2：同步块（更细粒度）
public void increment() {
    synchronized (this) {
        count++;
    }
}
```

### 锁原理

同一时刻，只有一个线程能获取对象的锁进入 synchronized 代码块，其他线程必须等待。

```java
public synchronized void methodA() { }  // 锁 this
public synchronized void methodB() { }  // 锁 this（同一把锁！）
// methodA 和 methodB 互斥，不能同时执行
```

### 小结

- 共享变量 + 多线程 = 需要同步
- `synchronized` 保证同一时刻只有一个线程执行
- 同步方法锁 this，同步块可以指定锁对象
