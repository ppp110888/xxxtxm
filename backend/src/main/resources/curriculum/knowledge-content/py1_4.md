## 条件判断 if-elif-else

### 基本语法

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

> ⚠️ Python 用**缩进**（4个空格）定义代码块，不用大括号 `{}`。

### 条件嵌套

```python
age = 20
has_ticket = True

if age >= 18:
    if has_ticket:
        print("可以入场")
    else:
        print("请先购票")
else:
    print("未成年人不得入场")
```

### 三元表达式

```python
# 语法：结果1 if 条件 else 结果2
score = 75
result = "及格" if score >= 60 else "不及格"
print(result)  # 及格
```

### match-case（Python 3.10+）

```python
status = 200

match status:
    case 200:
        print("OK")
    case 404:
        print("Not Found")
    case 500:
        print("Server Error")
    case _:
        print("Unknown")
```

### 常见技巧

```python
# 链式比较
age = 25
if 18 <= age <= 60:
    print("成年人")

# 空值判断
name = None
if name is None:
    print("名字未设置")

# 空容器判断
items = []
if not items:
    print("列表为空")

# in 判断
if "a" in "hello":
    print("包含字母 a")
```

### 常见错误

- ❌ `if score >= 90:` 忘记冒号
- ❌ 缩进不一致（混用空格和 Tab）
- ❌ `if score >= 90` 忘记写冒号
- ✅ Python 严格要求缩进统一

### 小结

- `if` / `elif` / `else` 构成条件判断
- 代码块用缩进定义，冒号结尾
- 支持链式比较 `18 <= age <= 60`
- Python 3.10+ 增加了 `match-case` 语法
