## 枚举 enum

### 基本使用

```java
public enum Day {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}

Day today = Day.MONDAY;
```

### 带字段和方法的枚举

```java
public enum Season {
    SPRING("春天", "温暖"),
    SUMMER("夏天", "炎热"),
    AUTUMN("秋天", "凉爽"),
    WINTER("冬天", "寒冷");

    private final String cnName;
    private final String weather;

    // 枚举的构造方法是私有的
    Season(String cnName, String weather) {
        this.cnName = cnName;
        this.weather = weather;
    }

    public String getCnName() { return cnName; }
    public String getWeather() { return weather; }
}

System.out.println(Season.SUMMER.getCnName()); // "夏天"
```

### 常用方法

```java
// values() — 获取所有枚举值
for (Day d : Day.values()) {
    System.out.println(d);
}

// valueOf() — 字符串转枚举
Day day = Day.valueOf("MONDAY");  // Day.MONDAY

// ordinal() — 获取序号（从0开始）
int pos = Day.WEDNESDAY.ordinal();  // 2
```

### switch 中使用

```java
switch (day) {
    case MONDAY, FRIDAY -> System.out.println("工作日");
    case SATURDAY, SUNDAY -> System.out.println("周末");
}
```

### 小结

- 枚举是有限个常量值的集合
- 构造方法默认 private
- values() 获取所有值，valueOf() 字符串转枚举
- 适合表示状态、类型、星期等有限选项
