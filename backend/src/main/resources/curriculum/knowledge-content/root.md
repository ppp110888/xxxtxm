# Java 基础教程

欢迎来到 Java 编程学习之旅！本课程专为零基础学习者设计，从最基本的语法开始，逐步深入到面向对象编程、核心类库、集合框架、IO 流、多线程以及 Java 8 新特性。

---

## 课程结构

| 章节 | 内容 | 难度 |
|------|------|------|
| 第1章 | Java 语言基础 | ⭐ 入门 |
| 第2章 | 面向对象编程 | ⭐⭐ 核心 |
| 第3章 | Java 核心类库 | ⭐⭐ 常用 |
| 第4章 | 集合框架 | ⭐⭐⭐ 进阶 |
| 第5章 | IO 流 | ⭐⭐⭐ 进阶 |
| 第6章 | 多线程 | ⭐⭐⭐⭐ 高级 |
| 第7章 | Java 8+ 新特性 | ⭐⭐⭐ 现代 |

## 学习建议

1. **循序渐进**：按照章节顺序学习，每章的知识点相互依赖
2. **动手实践**：每学完一个知识点后，完成对应的例题和练习题
3. **理解概念**：面向对象编程是 Java 的灵魂，多花时间理解
4. **善用调试**：遇到错误不要怕，仔细阅读报错信息是进步最快的方式

## 环境要求

- **JDK**: Java 17 或更高版本
- **IDE**: IntelliJ IDEA / Eclipse / VS Code
- **心态**: 耐心 + 好奇心 😊

> 准备好了吗？让我们开始吧！
