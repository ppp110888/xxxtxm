## threading 模块

### 创建线程的两种方式

```python
import threading

# 方式1：传递目标函数
def task(msg):
    print(f"执行: {msg}")

t = threading.Thread(target=task, args=("Hello",))
t.start()
t.join()

# 方式2：继承 Thread 类
class MyThread(threading.Thread):
    def __init__(self, name):
        super().__init__()
        self.thread_name = name

    def run(self):
        for i in range(3):
            print(f"{self.thread_name}: {i}")

t = MyThread("Worker")
t.start()
t.join()
```

### 线程属性

```python
import threading

t = threading.Thread(target=print, args=("test",))

# 设置守护线程（主线程退出时自动终止）
t.daemon = True

t.start()
print(t.name)           # 线程名称
print(t.is_alive())     # 是否存活
print(t.ident)          # 线程ID
print(threading.current_thread().name)  # 当前线程名
print(threading.active_count())         # 活跃线程数
```

### 线程间通信

```python
import threading
import time

# 使用全局变量 + 锁
shared_data = []
data_lock = threading.Lock()

def producer():
    for i in range(5):
        with data_lock:
            shared_data.append(i)
            print(f"生产: {i}")
        time.sleep(0.1)

def consumer():
    while True:
        with data_lock:
            if shared_data:
                item = shared_data.pop(0)
                print(f"消费: {item}")
            elif not producer_done:
                pass
            else:
                break
        time.sleep(0.15)

producer_done = False
t1 = threading.Thread(target=producer)
t2 = threading.Thread(target=consumer)
t1.start()
t2.start()
t1.join()
producer_done = True
t2.join()
```

### 线程本地存储

```python
import threading

# 每个线程拥有独立的存储空间
local = threading.local()

def process():
    local.value = threading.current_thread().name
    print(f"{local.value} 中的值: {local.value}")

threads = [threading.Thread(target=process) for _ in range(3)]
for t in threads:
    t.start()
for t in threads:
    t.join()
```

### 小结

- 创建线程：传 target 函数 或 继承 Thread 重写 run()
- 守护线程：`daemon=True` 随主线程退出
- 线程局部变量 `threading.local()` 用于线程隔离
- `active_count()` 查看活跃线程数
