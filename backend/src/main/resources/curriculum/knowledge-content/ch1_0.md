## Java 简介与环境搭建

### Java 是什么？

Java 是由 Sun Microsystems（后被 Oracle 收购）于 1995 年发布的一门**面向对象**编程语言。它的口号是 **"Write Once, Run Anywhere"（一次编写，到处运行）**。

Java 有三个重要版本：

| 版本 | 说明 |
|------|------|
| **Java SE** (Standard Edition) | 标准版，我们学习的基础 |
| **Java EE** (Enterprise Edition) | 企业版，用于 Web 开发 |
| **Java ME** (Micro Edition) | 微型版，用于嵌入式设备 |

### JVM 的工作原理

```
Java 源代码 (.java)
      │ javac 编译
      ▼
字节码 (.class)
      │ JVM 解释执行
      ▼
机器码 (运行在操作系统上)
```

**关键概念：**
- **JVM** (Java Virtual Machine)：Java 虚拟机，是 Java "跨平台"的关键
- **JRE** (Java Runtime Environment)：Java 运行环境 = JVM + 核心类库
- **JDK** (Java Development Kit)：Java 开发工具包 = JRE + 开发工具(编译器javac等)

### 环境搭建

#### 1. 安装 JDK

1. 访问 [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) 或 [OpenJDK](https://adoptium.net/)
2. 下载 JDK 17 或更高版本（本课程使用 JDK 17）
3. 按安装向导完成安装

#### 2. 配置环境变量 (Windows)

```bash
# 1. 找到 JDK 安装目录，例如：C:\Program Files\Java\jdk-17
# 2. 设置 JAVA_HOME 环境变量
JAVA_HOME = C:\Program Files\Java\jdk-17
# 3. 将 %JAVA_HOME%\bin 添加到 PATH
```

#### 3. 验证安装

```bash
java -version
# 输出示例: openjdk version "17.0.9" 2023-10-17

javac -version
# 输出示例: javac 17.0.9
```

### IDE 选择

推荐使用 **IntelliJ IDEA**（社区版免费），本平台的代码编辑器也支持在线编写 Java。

### 常见错误

- ❌ 只安装了 JRE 而没装 JDK，无法编译 Java 程序
- ✅ 确保安装的是 JDK，用 `javac -version` 验证

- ❌ 环境变量配置错误，命令行找不到 java
- ✅ 检查 JAVA_HOME 和 PATH 是否正确

### 小结

- Java 通过 JVM 实现跨平台
- JDK 包含开发工具，JRE 只含运行环境
- 使用 `javac` 编译，`java` 运行
- 安装 JDK 17+ 开始你的 Java 之旅
