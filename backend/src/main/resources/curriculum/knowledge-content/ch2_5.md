## 继承 extends

### 继承语法

```java
// 父类（基类）
public class Animal {
    String name;

    public void eat() {
        System.out.println(name + "在吃东西");
    }
}

// 子类（派生类）继承父类
public class Dog extends Animal {
    public void bark() {
        System.out.println(name + "在汪汪叫");
    }
}

Dog dog = new Dog();
dog.name = "旺财";   // 继承来的属性
dog.eat();           // 继承来的方法
dog.bark();          // 自己的方法
```

### super 关键字

```java
public class Dog extends Animal {
    public Dog(String name) {
        super();  // 调用父类无参构造（默认自动调用）
        this.name = name;
    }

    @Override
    public void eat() {
        super.eat();  // 调用父类的 eat 方法
        System.out.println("它吃的是狗粮");
    }
}
```

### Java 单继承

```java
// Java 只支持单继承（一个类只能有一个直接父类）
public class A extends B { }   // OK
public class A extends B, C { } // 编译错误！

// 但可以多层继承
public class A extends B { }
public class B extends C { }   // A → B → C 形成继承链
```

### Object 类

Java 中所有类默认继承 `Object` 类。常用方法：
- `toString()` — 对象的字符串表示
- `equals(Object obj)` — 判断两个对象是否相等
- `hashCode()` — 返回对象的哈希值

### 常见错误

- ❌ 试图继承 final 类：`class MyClass extends String { }` — String 是 final 的
- ✅ 检查父类是否有 final 修饰

### 小结

- `extends` 关键字实现继承
- 子类拥有父类所有非 private 成员
- `super` 引用父类对象
- Java 单继承，所有类根是 Object
