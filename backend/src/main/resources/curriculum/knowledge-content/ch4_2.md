## LinkedList

### 特点

LinkedList 底层是**双向链表**，插入和删除快（O(1)），随机访问慢（O(n)）。

```java
import java.util.LinkedList;

LinkedList<String> list = new LinkedList<>();
```

### 特有方法（作为队列/栈使用）

```java
// 作为队列（FIFO — 先进先出）
list.offer("第1个");     // 入队
list.offer("第2个");
String first = list.poll();  // 出队 → "第1个"
String peek = list.peek();   // 查看队首（不移除）

// 作为栈（LIFO — 后进先出）
list.push("A");         // 压栈
list.push("B");
String top = list.pop(); // 弹栈 → "B"
```

### ArrayList vs LinkedList 选择

| 场景 | 推荐 |
|------|------|
| 频繁随机访问（get by index） | ArrayList |
| 频繁头部/中间插入删除 | LinkedList |
| 需要队列/栈操作 | LinkedList |
| 通用场景 | ArrayList（更常用） |

### 小结

- LinkedList = 双向链表
- 插入删除快，随机访问慢
- 额外提供队列/栈操作方法
