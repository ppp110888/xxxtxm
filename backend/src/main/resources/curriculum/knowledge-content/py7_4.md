## 类型提示 Type Hints

### 基本类型提示

```python
# 变量类型提示
name: str = "小明"
age: int = 18
score: float = 95.5
is_student: bool = True
data: list = [1, 2, 3]

# 函数类型提示
def greet(name: str) -> str:
    return f"你好，{name}！"

def add(a: int, b: int) -> int:
    return a + b

def get_user(user_id: int) -> dict:
    return {"id": user_id, "name": "小明"}
```

### 复杂类型

```python
from typing import List, Dict, Tuple, Set, Optional, Union

# 容器类型
names: List[str] = ["小明", "小红"]
scores: Dict[str, int] = {"小明": 85, "小红": 92}
point: Tuple[int, int] = (3, 4)
ids: Set[int] = {1, 2, 3}

# Optional — 可能是 None
def find_user(name: str) -> Optional[Dict]:
    if name in users:
        return users[name]
    return None

# Union — 多种类型
def parse_value(val: str) -> Union[int, float, str]:
    if val.isdigit():
        return int(val)
    try:
        return float(val)
    except ValueError:
        return val
```

### 泛型与 Callable

```python
from typing import Callable, TypeVar

# Callable — 函数类型
T = TypeVar("T")

def apply(func: Callable[[int, int], int], a: int, b: int) -> int:
    return func(a, b)

# 函数接受两个int返回int
def compute(op: Callable[[int, int], int], x: int, y: int) -> int:
    return op(x, y)

# Any — 任意类型
from typing import Any

def debug_print(obj: Any) -> None:
    print(f"DEBUG: {obj}")
```

### Python 3.10+ 简化语法

```python
# 3.9+ list, dict 直接支持泛型
def process(nums: list[int]) -> dict[str, int]:
    return {"sum": sum(nums), "count": len(nums)}

# 3.10+ 用 | 替代 Union 和 Optional
def find_user(name: str) -> dict | None:  # 等价 Optional[Dict]
    ...

def parse(val: str) -> int | float | str:  # 等价 Union
    ...
```

### 类型检查工具

```bash
# mypy — 静态类型检查
pip install mypy
mypy myfile.py

# 注意：类型提示不影响运行时
# Python 不会在运行时强制检查类型
```

### 数据类 dataclass

```python
from dataclasses import dataclass

@dataclass
class Student:
    name: str
    age: int
    scores: list[float] = None  # 有默认值

    def average(self) -> float:
        if not self.scores:
            return 0.0
        return sum(self.scores) / len(self.scores)

s = Student("小明", 18, [85.0, 92.0, 78.0])
print(s.average())  # 85.0
```

### 小结

- 类型提示提高代码可读性和 IDE 支持
- 基本类型：`int`, `str`, `float`, `bool`, `list`, `dict`
- 复杂类型：`Optional`, `Union`, `Callable`, TypeVar
- Python 3.10+ 用 `|` 替代 `Union`/`Optional`
- 不影响运行时，用 `mypy` 静态检查
