## TreeMap

### 特点

与 HashMap 不同，TreeMap 的 Key 是**有序的**。

```java
Map<String, Integer> map = new TreeMap<>();
map.put("C", 3);
map.put("A", 1);
map.put("B", 2);
// Key 自动按自然顺序排列: A→B→C
```

### 自定义排序

```java
// 按 Key 降序
Map<String, Integer> map = new TreeMap<>(Comparator.reverseOrder());
```

### HashMap vs TreeMap

| 特性 | HashMap | TreeMap |
|------|---------|---------|
| 有序性 | 无序 | Key 自然排序 |
| 性能 | O(1) | O(log n) |
| 适用场景 | 通用 | 需要 Key 排序 |
| null key | 允许1个 | 不允许 |

### 小结

- TreeMap 的 Key 按自然顺序或 Comparator 排序
- 大多数场景用 HashMap（性能更好）
- 需要排序时用 TreeMap
