## 泛型深入

### 泛型方法

```java
// 泛型方法 — 在方法返回值前声明类型参数
public static <T> T getFirst(List<T> list) {
    return list.isEmpty() ? null : list.get(0);
}
```

### 通配符

```java
// ? extends T — 上界通配符（可读不可写）
public static double sumOfList(List<? extends Number> list) {
    double sum = 0;
    for (Number n : list) sum += n.doubleValue();
    return sum;
}

// ? super T — 下界通配符（可写不可读）
public static void addNumbers(List<? super Integer> list) {
    list.add(1);
    list.add(2);
}
```

### 通配符速查表

| 通配符 | 含义 | 读 | 写 |
|--------|------|-----|-----|
| `? extends T` | T 或 T 的子类 | ✓ | ✗ |
| `? super T` | T 或 T 的父类 | ✗ | ✓ |
| `?` | 任意类型 | (有限) | ✗ |

### 小结

- 泛型提供编译期类型安全检查
- `<T>` 是类型参数，`?` 是通配符
- `extends` 限制上界，`super` 限制下界
