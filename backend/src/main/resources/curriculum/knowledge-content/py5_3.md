## datetime 日期处理

### 获取当前时间

```python
from datetime import date, datetime, time, timedelta

now = datetime.now()
print(now)                # 2024-01-15 14:30:00.123456
print(now.date())         # 2024-01-15
print(now.time())         # 14:30:00.123456

today = date.today()
print(today)              # 2024-01-15
```

### 创建日期时间

```python
# 指定日期
d = date(2024, 1, 15)
t = time(14, 30, 0)
dt = datetime(2024, 1, 15, 14, 30, 0)

# 从字符串解析
dt1 = datetime.strptime("2024-01-15 14:30", "%Y-%m-%d %H:%M")
dt2 = datetime.strptime("15/01/2024", "%d/%m/%Y")
```

### 格式化输出

```python
now = datetime.now()

# strftime — datetime → 字符串
now.strftime("%Y-%m-%d")           # "2024-01-15"
now.strftime("%Y年%m月%d日")        # "2024年01月15日"
now.strftime("%H:%M:%S")           # "14:30:00"
now.strftime("%A")                 # "Monday"

# 常用格式化码
# %Y — 四位年份
# %m — 月份 (01-12)
# %d — 日 (01-31)
# %H — 时 (00-23)
# %M — 分 (00-59)
# %S — 秒 (00-59)
```

### timedelta — 时间差

```python
from datetime import timedelta

now = datetime.now()

# 加减运算
tomorrow = now + timedelta(days=1)
yesterday = now - timedelta(days=1)
one_hour_later = now + timedelta(hours=1)
one_week_ago = now - timedelta(weeks=1)

# 时间差
delta = tomorrow - yesterday
print(delta.days)        # 2
print(delta.total_seconds())  # 172800.0

# 创建 timedelta
td = timedelta(days=3, hours=5, minutes=30)
```

### 实用函数

```python
from datetime import datetime

# 判断闰年
def is_leap(year):
    return year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)

# 获取当月天数
def days_in_month(year, month):
    import calendar
    return calendar.monthrange(year, month)[1]

# 计算年龄
def calculate_age(birth_date):
    today = datetime.now().date()
    age = today.year - birth_date.year
    if today.month < birth_date.month or \
       (today.month == birth_date.month and today.day < birth_date.day):
        age -= 1
    return age
```

### 常见错误

- ❌ 月份或日期超出范围
- ✅ 使用 `calendar.monthrange()` 检查
- ❌ 时区混淆
- ✅ 明确 naive vs aware datetime

### 小结

- `datetime.now()` 获取当前时间
- `strptime` 解析字符串，`strftime` 格式化输出
- `timedelta` 处理时间差
- 要处理时区，使用 `pytz` 或 `zoneinfo`
