## 第一个程序 Hello World

### Hello World 程序

```python
# hello.py
print("Hello, World!")
```

单行代码即可！不需要类、不需要 main 方法、不需要分号。

### 逐行解析

```python
print("Hello, World!")
# print — 内置函数，用于输出
# "Hello, World!" — 字符串参数
# 执行后自动换行
```

### print 函数详解

```python
# 输出字符串
print("Hello")

# 输出多个值（自动空格分隔）
print("我叫", "小明", "今年", 18, "岁")
# 我叫 小明 今年 18 岁

# 自定义分隔符
print("a", "b", "c", sep="-")
# a-b-c

# 不换行输出
print("Hello", end=" ")
print("World")
# Hello World

# 格式化输出
name = "小明"
age = 18
print(f"我叫{name}，今年{age}岁")
# 我叫小明，今年18岁
```

### 注释

```python
# 这是单行注释

"""
这是多行注释（文档字符串）
可以写多行内容
"""
```

### 常见错误

- ❌ `print(Hello)` — 字符串忘写引号
- ✅ `print("Hello")` — 字符串必须加引号

- ❌ `print "Hello"` — Python 3 中 print 是函数，必须加括号
- ✅ `print("Hello")`

- ❌ 缩进错误：随意添加空格
- ✅ Python 用缩进组织代码，顶级代码不能缩进

### 小结

- `print()` 是 Python 的输出函数
- f-string `f"{变量}"` 是最方便的字符串格式化方式
- Python 用 `#` 写注释
- 代码顶级不要随意缩进
