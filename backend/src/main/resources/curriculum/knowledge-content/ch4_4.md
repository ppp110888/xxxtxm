## TreeSet 与 Comparable/Comparator

### TreeSet 特点

元素**自动排序**，底层是红黑树。

```java
// 自然排序（元素实现 Comparable）
Set<Integer> set = new TreeSet<>();
set.add(5);
set.add(1);
set.add(3);
System.out.println(set);  // [1, 3, 5] — 自动排序！
```

### 自然排序：Comparable

```java
public class Student implements Comparable<Student> {
    private String name;
    private int score;

    @Override
    public int compareTo(Student other) {
        // 按分数降序
        return Integer.compare(other.score, this.score);
    }
}
```

### 定制排序：Comparator

```java
// 按字符串长度排序
Set<String> set = new TreeSet<>(Comparator.comparingInt(String::length));

// Lambda 写法
Set<String> set2 = new TreeSet<>((a, b) -> a.length() - b.length());
```

### 小结

- TreeSet 元素自动排序
- Comparable：元素自身可比较（自然排序）
- Comparator：外部比较器（定制排序）
- compareTo 返回 0 被视为相等
