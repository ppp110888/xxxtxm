## Python 简介与环境搭建

### Python 是什么？

Python 是一门**解释型、面向对象**的高级编程语言，由 Guido van Rossum 于 1991 年发布。它的设计哲学强调**代码可读性**和**简洁的语法**。

### Python 的特点

| 特点 | 说明 |
|------|------|
| 简洁优雅 | 使用缩进定义代码块，无需分号和大括号 |
| 跨平台 | Windows / macOS / Linux 均可运行 |
| 丰富的库 | "自带电池" — 标准库功能强大，第三方库生态庞大 |
| 解释执行 | 无需编译，直接运行源码 |
| 动态类型 | 变量无需声明类型 |

### 安装 Python

```bash
# Windows: 下载安装包 https://www.python.org/downloads/
# 安装时务必勾选 "Add Python to PATH"

# 验证安装
python --version
# Python 3.11.5
```

### 运行 Python 代码

```bash
# 方式1: 交互式 (REPL)
python
>>> print("Hello")
Hello

# 方式2: 运行脚本
python hello.py

# 方式3: IDE (PyCharm / VS Code / 在线平台)
```

### 第一个程序

```python
# hello.py
print("Hello, Python!")
```

### 小结

- Python 是解释型语言，简洁优雅
- 安装后使用 `python` 命令运行
- `print()` 是最基本的输出函数
