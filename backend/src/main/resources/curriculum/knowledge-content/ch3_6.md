## 正则表达式基础

### 什么是正则表达式？

正则表达式（Regex）是一种**字符串模式匹配**工具，用于验证格式、提取信息、替换文本。

### Java 中使用正则

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;

// 方式1：String.matches() — 简单匹配
boolean isPhone = "13812345678".matches("\\d{11}");

// 方式2：Pattern + Matcher — 复杂操作
Pattern pattern = Pattern.compile("\\d+");
Matcher matcher = pattern.matcher("abc123def456");
while (matcher.find()) {
    System.out.println(matcher.group()); // 123, 456
}
```

### 常用元字符

| 元字符 | 含义 | 示例 |
|--------|------|------|
| `.` | 任意字符 | `a.c` → "abc", "a1c" |
| `\d` | 数字 [0-9] | `\d{3}` → "123" |
| `\w` | 单词字符 [a-zA-Z0-9_] | `\w+` |
| `\s` | 空白字符 (空格/tab/换行) | `a\sb` → "a b" |
| `^` | 字符串开始 | `^Hello` |
| `$` | 字符串结束 | `world$` |
| `*` | 0次或多次 | `ab*c` → "ac", "abc", "abbc" |
| `+` | 1次或多次 | `ab+c` → "abc", "abbc" |
| `?` | 0次或1次 | `ab?c` → "ac", "abc" |
| `{n}` | 恰好n次 | `\d{3}` → "123" |
| `{n,m}` | n到m次 | `\d{2,4}` |
| `[abc]` | a或b或c | `[aeiou]` |
| `[^abc]` | 非a非b非c | `[^0-9]` |

### 实用例子

```java
// 手机号验证
"13812345678".matches("1[3-9]\\d{9}");

// 邮箱验证
"user@example.com".matches("\\w+@\\w+\\.\\w+");

// 身份证号（18位）
"110101199001011234".matches("\\d{17}[\\dXx]");

// 替换
"abc123def456".replaceAll("\\d+", "NUM");  // "abcNUMdefNUM"

// 分割
"apple,banana;orange".split("[,;]");  // ["apple", "banana", "orange"]
```

### 常见错误

- ❌ Java 中反斜杠需要转义：`"\d"` 而不是 `"\d"`
- ✅ 正则在 Java 字符串中每个 `\` 代表正则的一个 `\`

### 小结

- 正则用于字符串模式匹配
- String 的 `matches` / `replaceAll` / `split` 都支持正则
- Java 中需要双反斜杠转义
- 复杂场景用 Pattern + Matcher
