## 包装类与自动装箱拆箱

### 为什么需要包装类？

基本类型（int、double 等）不是对象，无法参与泛型、集合等需要对象的地方。Java 为每种基本类型提供了对应的**包装类**。

| 基本类型 | 包装类 |
|----------|--------|
| `byte` | `Byte` |
| `short` | `Short` |
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |

### 自动装箱与拆箱 (Java 5+)

```java
// 自动装箱：基本类型 → 包装类
Integer num = 100;          // 等价于 Integer.valueOf(100)

// 自动拆箱：包装类 → 基本类型
int n = num;                // 等价于 num.intValue()

// 在集合中的使用
List<Integer> list = new ArrayList<>();
list.add(42);               // 自动装箱
int val = list.get(0);      // 自动拆箱
```

### 常用方法

```java
// 字符串 ↔ 数值
int i = Integer.parseInt("123");     // "123" → 123
double d = Double.parseDouble("3.14"); // "3.14" → 3.14
String s = Integer.toString(456);    // 456 → "456"

// 最大值/最小值
int maxVal = Integer.MAX_VALUE;  // 2147483647
int minVal = Integer.MIN_VALUE;  // -2147483648

// 进制转换
String bin = Integer.toBinaryString(10);  // "1010"
String hex = Integer.toHexString(255);    // "ff"
```

### 缓存陷阱（重要！）

```java
Integer a = 127;
Integer b = 127;
System.out.println(a == b);  // true — -128到127 从缓存获取

Integer c = 128;
Integer d = 128;
System.out.println(c == d);  // false — 超出缓存范围，不同对象！

// ✅ 始终用 equals 比较包装类
System.out.println(c.equals(d));  // true
```

### 小结

- 包装类让基本类型拥有对象特性
- 自动装箱/拆箱由编译器自动完成
- **比较包装类用 `equals()`，不要用 `==`**
- Integer 缓存了 -128~127 的值
