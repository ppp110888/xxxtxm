## 第一个程序 Hello World

### Hello World 程序

```java
// HelloWorld.java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### 逐行解析

```java
public class HelloWorld {        // ← 类名必须与文件名一致
    public static void main(String[] args) {  // ← main 方法是程序入口
        System.out.println("Hello, World!");  // ← 打印输出
    }
}
```

| 关键字 | 含义 |
|--------|------|
| `public` | 访问修饰符，表示公开可访问 |
| `class` | 声明一个类 |
| `static` | 静态方法，无需创建对象即可调用 |
| `void` | 该方法没有返回值 |
| `main` | 主方法名，JVM 的入口点，**固定写法** |
| `String[] args` | 命令行参数 |
| `System.out.println` | 打印一行并换行 |

### 编译与运行

```bash
# 1. 编译 — 生成 HelloWorld.class 字节码文件
javac HelloWorld.java

# 2. 运行 — JVM 执行字节码
java HelloWorld

# 输出:
Hello, World!
```

### print vs println vs printf

```java
System.out.print("Hello ");    // 不换行
System.out.print("World\n");   // \n 手动换行

System.out.println("第一行");  // 自动换行
System.out.println("第二行");

System.out.printf("我叫%s，今年%d岁%n", "小明", 18);  // 格式化输出
```

### 常见错误

- ❌ 类名和文件名不一致：`HelloWorld.java` 中写了 `class Hello`
- ✅ 类名必须与文件名完全一致（包括大小写）

- ❌ main 方法签名写错：`public void main()` 缺少 `static`
- ✅ 固定写法：`public static void main(String[] args)`

- ❌ 字符串忘写双引号：`System.out.println(Hello);`
- ✅ 字符串必须用双引号：`System.out.println("Hello");`

- ❌ 分号遗漏：每行语句末尾缺少 `;`
- ✅ Java 语句以分号结尾

### 小结

- Java 程序的基本单位是**类**（class）
- `main` 方法是程序的入口，签名是固定的
- `System.out.println()` 用于输出
- 编译用 `javac`，运行用 `java`
- 注意大小写、分号、双引号等细节
