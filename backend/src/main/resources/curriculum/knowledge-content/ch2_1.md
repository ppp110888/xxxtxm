## 类与对象

### 定义类

```java
public class Student {
    // 成员变量（属性）
    String name;
    int age;
    double score;

    // 成员方法（行为）
    public void introduce() {
        System.out.println("我叫" + name + "，今年" + age + "岁");
    }
}
```

### 创建对象

```java
// 使用 new 关键字创建对象
Student s1 = new Student();
s1.name = "小明";
s1.age = 18;
s1.score = 95.5;
s1.introduce();  // "我叫小明，今年18岁"

// 可以创建多个对象
Student s2 = new Student();
s2.name = "小红";
```

### 对象内存模型

```java
Student s1 = new Student();  // s1 是引用，指向堆中的 Student 对象
Student s2 = s1;             // s2 也指向同一个对象！
s2.name = "改名了";
System.out.println(s1.name); // "改名了" — 通过任何一个引用修改都会反映
```

### 类 vs 对象的区别

| 类（Class） | 对象（Object/Instance） |
|-------------|------------------------|
| 定义一次 | 可以创建多个 |
| 不占实际内存 | 每个对象占据独立内存 |
| 抽象的模板 | 具体的实例 |
| `class Student { }` | `new Student()` |

### 小结

- 类用 `class` 关键字定义
- 对象用 `new` 关键字创建
- 变量存储的是对象的引用（地址），不是对象本身
- 多个引用可以指向同一个对象
