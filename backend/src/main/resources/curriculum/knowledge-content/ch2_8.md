## 抽象类

### abstract 关键字

```java
// 抽象类 — 不能被实例化
public abstract class Shape {
    String color;

    // 抽象方法 — 没有方法体，由子类实现
    public abstract double getArea();

    // 普通方法 — 可以被子类继承
    public void printColor() {
        System.out.println("颜色：" + color);
    }
}

public class Circle extends Shape {
    double radius;

    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }
}
```

### 抽象类的特点

- 不能 `new Shape()` — 抽象类不能实例化
- 抽象方法必须被子类重写（除非子类也是抽象的）
- 可以有构造方法（给子类调用）
- 可以有普通方法

### 模板方法模式

```java
public abstract class Game {
    // 模板方法（final 防止子类覆盖流程）
    public final void play() {
        init();
        start();
        end();
    }

    abstract void init();
    abstract void start();
    abstract void end();
}
// 子类只需实现各个步骤，流程由父类控制
```

### 小结

- `abstract` 修饰的类不能被 new
- 抽象方法 = 只有声明没有实现的承诺
- 子类必须实现所有抽象方法
- 适合定义"模板"和"规范"
