## Collections 工具类

### 排序与查找

```java
List<Integer> list = new ArrayList<>(List.of(3, 1, 4, 1, 5));

Collections.sort(list);               // 升序排列
Collections.sort(list, Collections.reverseOrder()); // 降序
Collections.shuffle(list);            // 随机打乱
Collections.reverse(list);            // 反转

int idx = Collections.binarySearch(list, 3); // 二分查找（需先排序）

int max = Collections.max(list);       // 最大值
int min = Collections.min(list);       // 最小值
int freq = Collections.frequency(list, 1); // 元素出现次数
```

### 不可变集合

```java
List<String> unmodifiableList = Collections.unmodifiableList(list);
Set<String> unmodifiableSet = Collections.unmodifiableSet(set);
```

### 线程安全包装

```java
List<String> syncList = Collections.synchronizedList(new ArrayList<>());
Map<String, Integer> syncMap = Collections.synchronizedMap(new HashMap<>());
```

### 小结

- Collections 是操作集合的工具类
- sort/shuffle/reverse 常用
- 不可变集合防止意外修改
