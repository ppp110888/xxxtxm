## 运算符与表达式

### 算术运算符

```python
a, b = 10, 3

a + b    # 13  加法
a - b    # 7   减法
a * b    # 30  乘法
a / b    # 3.333...  除法（结果总是浮点数）
a // b   # 3   整除（地板除）
a % b    # 1   取模（余数）
a ** b   # 1000  幂运算 10^3
```

### 比较运算符

```python
a, b = 10, 3
a == b   # False  等于
a != b   # True   不等于
a > b    # True   大于
a < b    # False  小于
a >= b   # True   大于等于
a <= b   # False  小于等于
```

### 逻辑运算符

```python
# and — 与（两者都为 True）
True and True   # True
True and False  # False

# or — 或（至少一个为 True）
True or False   # True
False or False  # False

# not — 非（取反）
not True        # False
not False       # True
```

### 赋值运算符

```python
x = 5
x += 3   # x = x + 3 → 8
x -= 2   # x = x - 2 → 6
x *= 4   # x = x * 4 → 24
x /= 3   # x = x / 3 → 8.0
x //= 2  # x = x // 2 → 4.0
```

### 运算符优先级

1. `**` 幂运算
2. `* / // %` 乘除
3. `+ -` 加减
4. `> < >= <= == !=` 比较
5. `not` 逻辑非
6. `and` 逻辑与
7. `or` 逻辑或

> 不确定时，用括号 `()` 明确优先级！

### 小结

- `/` 总是返回浮点数，`//` 是整除
- `**` 是幂运算
- 比较运算返回 `bool`
- `and`/`or`/`not` 而非 `&&`/`||`/`!`
