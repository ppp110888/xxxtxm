## 文件读写基础

### 打开文件

```python
# open() 返回文件对象
f = open("data.txt", "r", encoding="utf-8")

# 模式速查
# 'r'  读取（默认）
# 'w'  写入（覆盖）
# 'a'  追加
# 'r+' 读写
# 'b'  二进制模式
```

### 读取文件

```python
# 读取全部内容
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

# 逐行读取
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())

# readlines
with open("data.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()  # list[str]
```

### 写入文件

```python
# 覆盖写入
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Hello, Python!\n")
    f.write("第二行\n")

# 追加写入
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("追加的内容\n")
```

### 编码处理

```python
# 中文文件务必指定 UTF-8
with open("中文文档.txt", "r", encoding="utf-8") as f:
    content = f.read()

# 常见编码问题
# UnicodeDecodeError → 尝试 encoding="gbk" 或 errors="ignore"
```

### 文件指针

```python
with open("data.txt", "r") as f:
    print(f.tell())        # 当前位置: 0
    f.read(10)             # 读10个字符
    print(f.tell())        # 当前位置: 10
    f.seek(0)              # 回到开头
    print(f.tell())        # 0
```

### 常见错误

- ❌ 忘记关闭文件（资源泄漏）
- ✅ 使用 `with` 语句自动关闭
- ❌ 中文编码乱码
- ✅ 指定 `encoding="utf-8"`

### 小结

- `open()` 打开文件，`with` 自动关闭
- `read()` 读全部，`readline()` 读一行
- `write()` 写入，模式 `w` 覆盖 `a` 追加
- 处理中文用 `encoding="utf-8"`
