## 创建线程 Thread / Runnable

### 方式一：继承 Thread

```java
class MyThread extends Thread {
    @Override
    public void run() {
        System.out.println("线程运行中");
    }
}

MyThread t = new MyThread();
t.start();  // 启动线程（自动调用 run）
// 不要直接调用 t.run()！那只是普通方法调用
```

### 方式二：实现 Runnable（推荐）

```java
class MyTask implements Runnable {
    @Override
    public void run() {
        System.out.println("任务执行中");
    }
}

Thread t = new Thread(new MyTask());
t.start();
```

### Lambda 简化

```java
Thread t = new Thread(() -> {
    System.out.println(Thread.currentThread().getName() + " 运行中");
});
t.start();
```

### Thread vs Runnable

| 方式 | 优点 | 缺点 |
|------|------|------|
| 继承 Thread | 简单 | Java 单继承，不能再继承其他类 |
| 实现 Runnable | 可同时继承其他类 | 多写一点代码 |

### 小结

- 启动线程用 `start()`，不是 `run()`
- Runnable 方式更灵活（推荐）
- Lambda 方式最简洁
