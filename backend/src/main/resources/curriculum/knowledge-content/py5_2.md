## random 与 math

### random 模块

```python
import random

# 随机整数
random.randint(1, 10)      # [1, 10] 随机整数
random.randrange(0, 10, 2) # [0, 2, 4, 6, 8] 中随机选

# 随机浮点数
random.random()            # [0, 1) 浮点数
random.uniform(1.5, 3.5)   # [1.5, 3.5] 浮点数

# 序列操作
fruits = ["苹果", "香蕉", "橘子"]
random.choice(fruits)          # 随机选一个
random.sample(fruits, 2)       # 随机选2个（不重复）
random.shuffle(fruits)         # 原地打乱

# 设置种子（让随机可复现）
random.seed(42)
```

### 加权随机

```python
import random

items = ["普通", "稀有", "史诗"]
weights = [70, 25, 5]  # 概率权重

result = random.choices(items, weights=weights, k=1)[0]
```

### math 模块

```python
import math

# 常数
math.pi       # 3.141592653589793
math.e        # 2.718281828459045

# 常用函数
math.sqrt(16)           # 4.0 — 平方根
math.pow(2, 10)         # 1024.0 — 幂
math.fabs(-3.5)         # 3.5 — 绝对值
math.factorial(5)       # 120 — 阶乘

# 取整
math.ceil(3.2)          # 4 — 向上取整
math.floor(3.8)         # 3 — 向下取整

# 三角函数
math.sin(math.pi / 2)   # 1.0
math.cos(0)             # 1.0

# 对数
math.log(100, 10)       # 2.0 — log₁₀(100)
math.log2(8)            # 3.0

# 最大公约数 / 最小公倍数
math.gcd(12, 18)        # 6
math.lcm(12, 18)        # 36
```

### 随机实战

```python
import random

# 生成验证码
def generate_code(length=6):
    chars = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    return "".join(random.choices(chars, k=length))

# 生成随机密码
def generate_password(length=12):
    import string
    chars = string.ascii_letters + string.digits + "!@#$%"
    return "".join(random.choices(chars, k=length))
```

### 小结

- `random` — 随机数生成，种子控制可复现性
- `random.choice` 随机选取，`random.shuffle` 洗牌
- `math` — 数学常量和函数
- `choices` 的 `weights` 参数支持加权随机
