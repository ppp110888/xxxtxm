## 方法的定义与调用

### 方法是什么？

**方法（Method）** 是一段有名字的可重复使用的代码块，类似于"数学中的函数"。

```java
修饰符 返回类型 方法名(参数列表) {
    // 方法体
    return 返回值;
}
```

### 定义方法

```java
// 无返回值的方法
public static void sayHello() {
    System.out.println("Hello!");
}

// 有返回值的方法
public static int add(int a, int b) {
    return a + b;
}

// 多个参数
public static double getAverage(double x, double y, double z) {
    return (x + y + z) / 3.0;
}
```

### 调用方法

```java
sayHello();                    // 调用无返回值方法

int sum = add(3, 5);          // 调用有返回值方法，sum = 8

double avg = getAverage(80.5, 90.0, 95.5);  // avg = 88.67
```

### 方法重载 (Overload)

**同名方法，参数不同**（个数、类型或顺序不同）：

```java
public static int max(int a, int b) {
    return a > b ? a : b;
}

public static double max(double a, double b) {  // 参数类型不同
    return a > b ? a : b;
}

public static int max(int a, int b, int c) {    // 参数个数不同
    return max(max(a, b), c);
}
```

### 参数传递

Java 中参数传递是**值传递**：

```java
public static void changeValue(int x) {
    x = 100;  // 只改变了局部变量 x，不影响外部
}

int num = 50;
changeValue(num);
System.out.println(num);  // 仍然是 50
```

### 常见错误

- ❌ 方法名写错了返回值类型：`public int getName()` 忘记 return
- ✅ 声明了返回值类型就必须 return 对应的值

- ❌ 调用 `add(3.5, 2)` 但只定义了 `add(int, int)`
- ✅ 确保参数类型匹配，或定义重载版本

- ❌ 方法内定义方法（Java 不允许方法嵌套）
- ✅ 方法在类中平级定义

### 小结

- 方法 = 可重复使用的代码块
- `void` 表示无返回值，否则需要 `return`
- 方法重载：同名不同参
- Java 参数传递是值传递
