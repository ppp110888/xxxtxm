## String 类详解

### String 的不可变性

```java
String s = "Hello";
s = s + " World";  // 创建了新的 String 对象，原对象不变
```

String 被 `final` 修饰，一旦创建就**不可修改**。每次拼接都会创建新对象。

### 常用方法

```java
String s = "Hello, Java!";

// 基本信息
int len = s.length();          // 12 — 字符串长度
char c = s.charAt(0);          // 'H' — 第0个字符

// 查找
int idx = s.indexOf("Java");   // 7 — 查找子串位置
boolean contains = s.contains("llo"); // true

// 截取
String sub = s.substring(7);   // "Java!" — 从索引7到末尾
String sub2 = s.substring(0, 5); // "Hello" — 索引[0,5)

// 替换
String rep = s.replace("Java", "World"); // "Hello, World!"

// 分割
String[] parts = "a,b,c".split(",");  // ["a", "b", "c"]

// 大小写
String upper = s.toUpperCase();  // "HELLO, JAVA!"
String lower = s.toLowerCase();  // "hello, java!"

// 去空格
String trimmed = "  hello  ".trim(); // "hello"

// 比较（重要！）
boolean eq = "abc".equals("abc");       // true — 内容比较
boolean eqIg = "Abc".equalsIgnoreCase("abc"); // true — 忽略大小写
```

### 字符串拼接性能

```java
// ❌ 循环中拼接字符串 — 每次创建新对象，性能差
String s = "";
for (int i = 0; i < 10000; i++) {
    s += i;  // 每次循环都创建新 String 对象！
}

// ✅ 使用 StringBuilder 高效拼接
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i);
}
String result = sb.toString();  // 一次转换
```

### 字符串常量池

```java
String a = "hello";       // 从常量池获取
String b = "hello";       // 指向同一个常量池对象
System.out.println(a == b); // true — 同一个对象！

String c = new String("hello"); // 强制在堆上创建新对象
System.out.println(a == c);     // false — 不同对象
System.out.println(a.equals(c)); // true — 内容相同
```

### 小结

- String 不可变，频繁拼接用 StringBuilder
- `equals()` 比较内容，`==` 比较引用地址
- 字面量字符串存储在常量池中
- `split()` 的参数是正则表达式
