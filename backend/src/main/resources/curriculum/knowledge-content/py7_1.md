## 虚拟环境与 pip

### 为什么需要虚拟环境？

不同项目可能依赖不同版本的同一库。虚拟环境让每个项目有**独立的 Python 环境**。

### venv — 创建虚拟环境

```bash
# 创建虚拟环境
python -m venv myenv

# 目录结构
myenv/
├── Scripts/    # 可执行文件 (Windows)
│   ├── python.exe
│   └── activate
├── Lib/        # 第三方库
└── pyvenv.cfg
```

### 激活虚拟环境

```bash
# Windows
myenv\Scripts\activate

# macOS / Linux
source myenv/bin/activate

# 激活后，提示符前会显示环境名
(myenv) $

# 退出
deactivate
```

### pip — 包管理器

```bash
# 安装包
pip install requests
pip install numpy pandas         # 一次装多个
pip install django==4.2.0        # 指定版本
pip install "package>=1.0,<2.0"  # 版本范围

# 卸载
pip uninstall requests

# 查看已安装包
pip list
pip show requests                # 详细信息

# 升级 pip 自身
python -m pip install --upgrade pip
```

### requirements.txt

```bash
# 生成依赖文件
pip freeze > requirements.txt

# 内容示例
# requests==2.31.0
# numpy==1.26.2
# pandas==2.1.4

# 安装所有依赖
pip install -r requirements.txt
```

### 常见问题

```bash
# 网络慢 → 使用国内镜像
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple numpy

# 权限问题 → 用户级安装
pip install --user package_name

# 缓存清理
pip cache purge
```

### 小结

- `python -m venv name` 创建虚拟环境
- 激活后 pip install 安装到虚拟环境中
- `pip freeze > requirements.txt` 导出依赖
- 每个项目一个虚拟环境是最佳实践
