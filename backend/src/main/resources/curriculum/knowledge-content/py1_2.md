## 变量与数据类型

### 变量是什么？

**变量**是内存中一块被命名的存储空间。Python 中变量**无需声明类型**，赋值即创建。

```python
age = 18           # 整数
price = 9.99       # 浮点数
name = "小明"       # 字符串
is_student = True  # 布尔值
```

### Python 的基本数据类型

| 类型 | 关键字 | 示例 | 说明 |
|------|--------|------|------|
| 整数 | `int` | `42`, `-10`, `0` | 任意精度 |
| 浮点数 | `float` | `3.14`, `-0.5` | 双精度 |
| 字符串 | `str` | `"hello"`, `'你好'` | 单引号/双引号均可 |
| 布尔值 | `bool` | `True`, `False` | 首字母大写 |
| 空值 | `None` | `None` | 表示"无" |

### 类型检查与转换

```python
# 查看类型
print(type(42))     # <class 'int'>
print(type(3.14))   # <class 'float'>
print(type("hi"))   # <class 'str'>

# 类型转换
int("123")    # 123
float("3.14") # 3.14
str(100)      # "100"
bool(1)       # True
bool(0)       # False
```

### 命名规则

```python
# ✅ 合法命名
student_age = 18     # 蛇形命名（推荐）
firstName = "Tom"     # 驼峰命名也可用
count2 = 10           # 数字可用，但不能开头
PI = 3.14159          # 常量用全大写

# ❌ 非法命名
2count = 10           # 不能以数字开头
my-age = 5            # 不能有连字符
class = "Math"        # 不能是关键字
```

### 动态类型

```python
x = 10        # x 是 int
x = "hello"   # x 现在是 str — 完全合法！
x = [1, 2, 3] # x 现在是 list — 也没问题！
```

### 常见错误

- ❌ 使用未定义的变量：`print(name)` 但 `name` 未赋值
- ✅ 先赋值再使用：`name = "Tom"; print(name)`

- ❌ 类型不匹配：`"我" + 18` — 字符串不能直接加整数
- ✅ `"我" + str(18)` 或 `f"我{18}"`

### 小结

- Python 是动态类型语言，变量无需声明类型
- 基本类型：int、float、str、bool、None
- 使用 `type()` 查看类型，使用 `int()`/`str()` 等转换类型
- 变量命名用蛇形命名法，不能以数字开头
