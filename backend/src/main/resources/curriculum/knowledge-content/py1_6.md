## 列表与元组

### 列表 list

列表是 Python 最常用的容器类型，**可变、有序**。

```python
# 创建列表
nums = [1, 2, 3, 4, 5]
fruits = ["苹果", "香蕉", "橘子"]
mixed = [1, "hello", 3.14, True]  # 可以混合类型
empty = []

# 访问元素（索引从0开始）
print(fruits[0])   # 苹果
print(fruits[-1])  # 橘子（倒数第一个）
print(fruits[1:3]) # ['香蕉', '橘子'] 切片
```

### 列表操作

```python
nums = [1, 2, 3]

# 添加
nums.append(4)       # [1, 2, 3, 4] — 末尾添加
nums.insert(0, 0)    # [0, 1, 2, 3, 4] — 指定位置插入
nums.extend([5, 6])  # [0, 1, 2, 3, 4, 5, 6] — 扩展

# 删除
nums.pop()           # 删除并返回最后一个元素
nums.pop(0)          # 删除并返回索引0的元素
nums.remove(3)       # 删除第一个值为3的元素
del nums[0]          # 删除索引0的元素

# 其他操作
len(nums)            # 长度
3 in nums            # 是否包含
nums.sort()          # 原地排序
nums.reverse()       # 原地反转
sorted(nums)         # 返回新排序列表，原列表不变
```

### 列表推导式

```python
# 基本语法
squares = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]

# 带条件
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]

# 嵌套
matrix = [[i*j for j in range(3)] for i in range(3)]
```

### 元组 tuple

元组是**不可变**序列，创建后不能修改。

```python
# 创建元组
point = (3, 4)
single = (1,)    # 单元素元组，必须加逗号！
empty = ()

# 访问（同列表）
x, y = point     # 元组解包
print(x, y)      # 3 4

# 为什么用元组？
# 1. 不可变 — 更安全
# 2. 可哈希 — 可作为字典的键
# 3. 效率略高于列表
```

### 常见错误

- ❌ `nums[5]` — 索引越界
- ✅ 先检查 `len(nums)`
- ❌ `nums.append([4, 5])` 想加多个元素
- ✅ `nums.extend([4, 5])` 扩展多个元素

### 小结

- 列表可变、有序，是最常用的容器
- 索引从 0 开始，支持负索引和切片
- 列表推导式简洁高效
- 元组是不可变序列，支持解包
