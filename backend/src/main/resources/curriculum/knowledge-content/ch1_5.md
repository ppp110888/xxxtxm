## 循环结构 for / while / do-while

### for 循环

```java
for (int i = 0; i < 10; i++) {
    System.out.println("第" + i + "次循环");
}
```

**执行顺序：** ①初始化 → ②判断条件 → ③执行循环体 → ④更新变量 → 回到步骤②

### while 循环

```java
int i = 0;
while (i < 10) {
    System.out.println(i);
    i++;  // 不要忘记更新循环变量！
}
```

### do-while 循环

```java
int i = 0;
do {
    System.out.println(i);
    i++;
} while (i < 10);
```

**区别：** do-while 的循环体**至少执行一次**，因为条件判断在循环体之后。

### break 和 continue

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) break;      // 跳出整个循环
    if (i % 2 == 0) continue; // 跳过本次循环，继续下一次
    System.out.println(i);   // 只输出奇数
}
```

| 关键字 | 作用 |
|--------|------|
| `break` | 终止当前循环 |
| `continue` | 跳过本次循环剩余代码，进入下一次迭代 |

### 嵌套循环

```java
// 打印九九乘法表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "x" + i + "=" + (i*j) + "\t");
    }
    System.out.println();
}
```

### 常见错误

- ❌ 忘记更新循环变量，导致**死循环**：`while (i < 10) { }` 中没有 i++
- ✅ 确保循环变量在循环体内被正确更新

- ❌ for 循环后面加了分号：`for (int i=0; i<10; i++);` — 循环体为空！
- ✅ 去掉多余的分号

- ❌ 循环边界错误（off-by-one）：`for (int i=0; i<=10; i++)` 循环了 11 次
- ✅ 仔细考虑用 `<` 还是 `<=`

### 小结

- for 循环适合已知循环次数的情况
- while 适合条件驱动的循环
- do-while 至少执行一次
- break 跳出，continue 跳过
- 嵌套循环：外层控制行，内层控制列
