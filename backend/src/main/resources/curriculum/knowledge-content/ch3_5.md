## 日期与时间 API

### Java 8 时间 API (推荐)

Java 8 引入了 `java.time` 包，替代了旧的 `Date` 和 `Calendar`。

```java
import java.time.*;

// 当前日期/时间
LocalDate today = LocalDate.now();          // 2026-06-09
LocalTime now = LocalTime.now();            // 14:30:00.123
LocalDateTime dt = LocalDateTime.now();     // 2026-06-09T14:30:00.123

// 创建指定时间
LocalDate date = LocalDate.of(2026, 6, 1);
LocalTime time = LocalTime.of(14, 30, 0);
LocalDateTime dateTime = LocalDateTime.of(2026, 6, 1, 14, 30);
```

### 日期运算

```java
LocalDate today = LocalDate.now();

// 加减
LocalDate tomorrow = today.plusDays(1);
LocalDate yesterday = today.minusDays(1);
LocalDate nextMonth = today.plusMonths(1);
LocalDate nextYear = today.plusYears(1);

// 计算差值
Period period = Period.between(today, tomorrow);
int days = period.getDays();  // 1

// 比较
boolean after = tomorrow.isAfter(today);   // true
boolean before = yesterday.isBefore(today); // true
```

### 格式化

```java
import java.time.format.DateTimeFormatter;

LocalDateTime now = LocalDateTime.now();

// 格式化
DateTimeFormatter fmt = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String str = now.format(fmt);  // "2026-06-09 14:30:00"

// 解析
LocalDateTime parsed = LocalDateTime.parse("2026-06-09 14:30:00", fmt);
```

### 时间戳

```java
import java.time.Instant;

// 获取当前时间戳（毫秒）
long millis = System.currentTimeMillis();

// Instant → LocalDateTime
LocalDateTime dt = LocalDateTime.ofInstant(
    Instant.ofEpochMilli(millis), ZoneId.systemDefault());
```

### 小结

- 用 `java.time` 包，不要用旧的 Date/Calendar
- `LocalDate` = 日期，`LocalTime` = 时间，`LocalDateTime` = 日期+时间
- `DateTimeFormatter` 用于格式化和解析
- 日期运算用 `plus/minus` 方法
