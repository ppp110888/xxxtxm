## 面向对象思想概述

### 什么是面向对象？

**面向对象编程（OOP）** 是一种以"对象"为中心的编程思想。它将数据和行为封装在一起，模拟现实世界的事物关系。

### 三大特性

| 特性 | 含义 | 生活类比 |
|------|------|----------|
| **封装** | 隐藏内部实现，只暴露接口 | 手机：你只需要知道按钮，不需要知道内部芯片 |
| **继承** | 子类继承父类的属性和方法 | 猫/狗继承"动物"的共同特征 |
| **多态** | 同一个方法在不同对象中表现出不同行为 | "叫"这个行为：猫叫 vs 狗叫 vs 鸟叫 |

### 类 vs 对象

```
类（Class）  →  蓝图/模具    →  String
对象（Object）→  具体实例    →  "Hello"、"World"（每个字符串都是 String 类的一个对象）
```

### 为什么用 OOP？

- **复用性**：继承让代码不重复
- **扩展性**：多态让程序容易扩展
- **维护性**：封装让修改变化局部化
- **可读性**：代码结构更接近人类思维

### 小结

- OOP 三大特性：封装、继承、多态
- 类 = 模板，对象 = 实例
- OOP 让代码更易维护和扩展
