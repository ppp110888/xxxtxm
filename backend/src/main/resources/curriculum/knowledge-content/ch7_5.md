## 函数式接口

### 什么是函数式接口？

**只有一个抽象方法**的接口，可以用 Lambda 实现。用 `@FunctionalInterface` 注解标注。

```java
@FunctionalInterface
public interface MyFunction {
    int apply(int a, int b);  // 唯一抽象方法
}
MyFunction add = (a, b) -> a + b;
```

### 常用函数式接口

| 接口 | 方法签名 | 用途 |
|------|----------|------|
| `Function<T,R>` | `R apply(T t)` | 转换（T → R） |
| `Predicate<T>` | `boolean test(T t)` | 判断/过滤 |
| `Consumer<T>` | `void accept(T t)` | 消费数据 |
| `Supplier<T>` | `T get()` | 提供数据 |
| `BiFunction<T,U,R>` | `R apply(T t, U u)` | 双参数转换 |
| `UnaryOperator<T>` | `T apply(T t)` | 一元运算 |
| `BinaryOperator<T>` | `T apply(T t1, T t2)` | 二元运算 |

### 使用示例

```java
// Predicate — 判断
Predicate<Integer> isAdult = age -> age >= 18;

// Function — 转换
Function<String, Integer> strLength = String::length;

// Consumer — 消费
Consumer<String> printer = System.out::println;

// Supplier — 供应
Supplier<Double> random = Math::random;
```

### 小结

- 函数式接口 = 只有一个抽象方法的接口
- Java 内置了常用的函数式接口（java.util.function）
- Lambda 的本质是实现函数式接口
