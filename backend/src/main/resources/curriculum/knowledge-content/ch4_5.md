## HashMap

### 概念

HashMap 存储**键值对（Key-Value）**，Key 不可重复，Value 可重复。

```java
Map<String, Integer> map = new HashMap<>();
```

### 常用方法

```java
Map<String, Integer> scores = new HashMap<>();

// 增/改
scores.put("小明", 95);      // 新增
scores.put("小明", 100);     // 覆盖（同一个key）

// 删
scores.remove("小明");

// 查
Integer score = scores.get("小明");        // 按key查value
boolean has = scores.containsKey("小明");    // 是否包含key
int size = scores.size();

// 获取或默认值
Integer val = scores.getOrDefault("小红", 0);  // 不存在返回0
```

### 遍历方式

```java
// 遍历所有 key
for (String key : map.keySet()) {
    System.out.println(key + " -> " + map.get(key));
}

// 遍历所有 value
for (Integer v : map.values()) {
    System.out.println(v);
}

// 遍历所有 entry（推荐，效率最高）
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " -> " + entry.getValue());
}

// forEach + Lambda（最简洁）
map.forEach((k, v) -> System.out.println(k + " -> " + v));
```

### 小结

- HashMap 存储键值对，Key 基于哈希去重
- 遍历推荐 `entrySet()` 或 `forEach`
- Key 对象应重写 equals + hashCode
