## 接口 interface

### 定义与实现

```java
// 定义接口
public interface Flyable {
    void fly();  // 接口方法默认是 public abstract
}

// 实现接口
public class Bird implements Flyable {
    @Override
    public void fly() {
        System.out.println("鸟儿扇动翅膀飞行");
    }
}

public class Airplane implements Flyable {
    @Override
    public void fly() {
        System.out.println("飞机用引擎飞行");
    }
}
```

### 多接口实现

```java
// 一个类可以实现多个接口（弥补单继承的不足）
public class Duck implements Flyable, Swimmable, Walkable {
    @Override public void fly() { /* ... */ }
    @Override public void swim() { /* ... */ }
    @Override public void walk() { /* ... */ }
}
```

### 接口 vs 抽象类

| 特性 | 接口 | 抽象类 |
|------|------|--------|
| 关键字 | `interface` / `implements` | `abstract` / `extends` |
| 多继承 | 可实现多个接口 | 只能继承一个 |
| 构造方法 | 没有 | 有 |
| 成员变量 | 只能是常量 (public static final) | 可以有普通成员变量 |
| Java 8+ | 支持 default/static 方法 | 支持所有方法类型 |

### default 方法 (Java 8+)

```java
public interface Animal {
    void makeSound();

    // default 方法 — 有默认实现，实现类可以覆写也可以不覆写
    default void sleep() {
        System.out.println("Zzz...");
    }
}
```

### 小结

- 接口定义"能做什么"的规范
- 一个类可以实现多个接口
- Java 8+ 接口可以有 default 方法
- 接口是 Java 实现多态的重要手段
