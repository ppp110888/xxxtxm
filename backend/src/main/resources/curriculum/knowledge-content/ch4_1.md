## ArrayList

### 特点

ArrayList 是**动态数组**，可以自动扩容，随机访问快（O(1)）。

```java
import java.util.ArrayList;
import java.util.List;

List<String> list = new ArrayList<>();
```

### 常用方法

```java
List<String> fruits = new ArrayList<>();

// 增
fruits.add("苹果");
fruits.add(0, "香蕉");  // 在索引0处插入
fruits.addAll(List.of("橘子", "葡萄"));

// 删
fruits.remove(0);           // 按索引删除
fruits.remove("苹果");      // 按对象删除
fruits.clear();             // 清空

// 改
fruits.set(0, "大苹果");    // 替换索引0的元素

// 查
String first = fruits.get(0);        // 按索引获取
boolean has = fruits.contains("苹果"); // 是否包含
int idx = fruits.indexOf("苹果");     // 查找位置
int size = fruits.size();            // 元素个数
```

### 遍历方式

```java
// for 循环（有索引，可修改）
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

// 增强 for-each（简洁）
for (String fruit : list) {
    System.out.println(fruit);
}

// forEach + Lambda（最简洁）
list.forEach(fruit -> System.out.println(fruit));

// 迭代器（可安全删除）
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    if (it.next().startsWith("A")) it.remove();
}
```

### ArrayList vs 数组

| 特性 | 数组 | ArrayList |
|------|------|-----------|
| 长度 | 固定 | 动态扩容 |
| 泛型 | 支持 | 支持 |
| 基本类型 | 支持 | 需用包装类 |
| 性能 | 略快 | 略慢（有装箱开销） |

### 小结

- ArrayList 是最常用的 List 实现
- 随机访问快，中间插入/删除慢
- 遍历用 for-each 或 forEach
