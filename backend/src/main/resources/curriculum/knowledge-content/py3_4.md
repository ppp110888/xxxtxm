## 装饰器

### 闭包回顾

```python
def make_multiplier(n):
    def multiplier(x):
        return x * n
    return multiplier

times3 = make_multiplier(3)
print(times3(10))  # 30
```

### 装饰器基础

装饰器是一个接收函数、返回函数的**高阶函数**。

```python
def log(func):
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        result = func(*args, **kwargs)
        print(f"{func.__name__} 返回 {result}")
        return result
    return wrapper

@log
def add(a, b):
    return a + b

print(add(3, 5))
# 调用 add
# add 返回 8
# 8
```

### 带参数的装饰器

```python
def repeat(times):
    """重复执行指定次数"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def say_hello():
    print("Hello!")

say_hello()  # 打印三次 Hello!
```

### 保留函数元信息

```python
from functools import wraps

def log(func):
    @wraps(func)  # 保留原函数的 name 和 docstring
    def wrapper(*args, **kwargs):
        print(f"调用 {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@log
def greet(name):
    """向指定人打招呼"""
    return f"你好, {name}!"

print(greet.__name__)  # greet (没有 @wraps 会是 wrapper)
print(greet.__doc__)   # 向指定人打招呼
```

### 常用内建装饰器

```python
# @property — 属性装饰器
class Person:
    def __init__(self, name):
        self._name = name

    @property
    def name(self):
        return self._name

# @staticmethod — 静态方法
class Math:
    @staticmethod
    def add(a, b):
        return a + b

# @classmethod — 类方法
class Date:
    @classmethod
    def from_string(cls, s):
        y, m, d = map(int, s.split("-"))
        return cls(y, m, d)
```

### 小结

- 装饰器 = 接收函数、返回函数的高阶函数
- `@decorator` 语法糖
- `@wraps(func)` 保留函数元信息
- 带参数装饰器需要三层嵌套
- 内建装饰器：`@property`, `@staticmethod`, `@classmethod`
