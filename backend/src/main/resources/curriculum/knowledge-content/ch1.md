# 第1章 Java 语言基础

> 本章是 Java 入门的第一站。我们将从零开始，学习 Java 的基本语法、数据类型、控制流程，为后续的面向对象编程打下坚实基础。

---

## 本章目标

完成本章学习后，你将能够：

1. 理解 Java 的跨平台原理，搭建开发环境
2. 编写并运行你的第一个 Java 程序
3. 使用变量存储数据，理解各种数据类型
4. 掌握运算符和表达式
5. 使用条件判断和循环控制程序流程
6. 使用数组存储批量数据
7. 定义和调用方法来组织代码
