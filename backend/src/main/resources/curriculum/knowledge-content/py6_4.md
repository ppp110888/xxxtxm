## asyncio 异步编程

### 基本概念

**asyncio** 是 Python 的异步 IO 框架，采用**事件循环 + 协程**模型。

```python
import asyncio

# 定义协程 — async def
async def say_hello():
    print("Hello")
    await asyncio.sleep(1)  # 模拟异步IO
    print("World")

# 运行
asyncio.run(say_hello())
```

### async / await

```python
# async def — 定义协程函数
async def fetch_data(url):
    print(f"开始获取 {url}")
    await asyncio.sleep(1)  # 模拟网络请求
    return f"{url} 的数据"

# await — 等待协程完成
async def main():
    result = await fetch_data("api.example.com")
    print(result)

asyncio.run(main())
```

### 并发执行

```python
import asyncio

async def download(url, delay):
    await asyncio.sleep(delay)
    return f"{url} 下载完成 (耗时{delay}s)"

async def main():
    # gather — 并发执行
    results = await asyncio.gather(
        download("file1", 2),
        download("file2", 1),
        download("file3", 3),
    )
    print(results)  # 三个结果，总耗时~3s而非6s

asyncio.run(main())
```

### create_task — 创建任务

```python
async def main():
    # 创建任务（不等待，立即返回）
    task1 = asyncio.create_task(download("A", 2))
    task2 = asyncio.create_task(download("B", 1))

    print("任务已创建，等待完成...")
    result1 = await task1
    result2 = await task2
    print(result1, result2)
```

### 超时控制

```python
async def slow_task():
    await asyncio.sleep(10)
    return "完成"

async def main():
    try:
        result = await asyncio.wait_for(slow_task(), timeout=3)
        print(result)
    except asyncio.TimeoutError:
        print("任务超时！")
```

### 异步上下文管理器

```python
import asyncio

class AsyncResource:
    async def __aenter__(self):
        print("获取资源")
        await asyncio.sleep(0.1)
        return self

    async def __aexit__(self, *args):
        print("释放资源")
        await asyncio.sleep(0.1)

async def main():
    async with AsyncResource() as r:
        print("使用资源")

asyncio.run(main())
```

### asyncio vs threading

| 场景 | 推荐 |
|------|------|
| IO 密集 (网络请求、文件) | asyncio |
| CPU 密集 | multiprocessing |
| 已有同步代码，快速改造 | threading |
| 高并发连接 (成千上万) | asyncio |

### 小结

- `async def` 定义协程，`await` 等待协程
- `asyncio.gather()` 并发执行多个协程
- `asyncio.create_task()` 创建后台任务
- `asyncio.wait_for()` 超时控制
- asyncio 适合高并发 IO 场景
