## Math 与 Random

### Math 类

```java
// 常量
double pi = Math.PI;       // 3.14159...
double e = Math.E;         // 2.71828...

// 基础运算
int big = Math.max(10, 20);    // 20 — 最大值
int small = Math.min(10, 20);  // 10 — 最小值
int abs = Math.abs(-5);        // 5 — 绝对值

// 幂与根
double pow = Math.pow(2, 10);    // 1024.0 — 2的10次方
double sqrt = Math.sqrt(16);     // 4.0 — 平方根
double cbrt = Math.cbrt(27);     // 3.0 — 立方根

// 取整
double ceil = Math.ceil(3.14);     // 4.0 — 向上取整
double floor = Math.floor(3.14);   // 3.0 — 向下取整
long round = Math.round(3.5);      // 4 — 四舍五入

// 三角函数
double sin = Math.sin(Math.PI / 6);  // 0.5 (sin 30°)
double cos = Math.cos(0);            // 1.0
```

### Random 类

```java
import java.util.Random;

Random rand = new Random();

int n = rand.nextInt();        // 随机 int（全范围）
int dice = rand.nextInt(6) + 1; // 1~6 的随机整数
double d = rand.nextDouble();  // 0.0 ~ 1.0 之间
boolean b = rand.nextBoolean(); // 随机 true/false
```

### ThreadLocalRandom（推荐）

多线程环境下性能更好：

```java
import java.util.concurrent.ThreadLocalRandom;

// 生成 [min, max] 范围内的随机整数
int random = ThreadLocalRandom.current().nextInt(1, 101); // 1~100
```

### 常见错误

- ❌ `Math.round()` 对负数：`Math.round(-1.5)` → `-1`（不是 -2！）
- ✅ 负数四舍五入注意取舍规则

### 小结

- Math 提供数学常量和运算方法
- Random 生成伪随机数
- 多线程环境优先用 ThreadLocalRandom
