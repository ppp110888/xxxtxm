## Stream API

### 创建 Stream

```java
// 从集合
List<String> list = List.of("a", "b", "c");
Stream<String> stream = list.stream();

// 从数组
Stream<Integer> numStream = Arrays.stream(new Integer[]{1, 2, 3});

// 直接创建
Stream<String> s = Stream.of("x", "y", "z");
```

### 中间操作（返回 Stream，可链式调用）

```java
List<String> list = List.of("apple", "banana", "cat", "dog");

// filter — 过滤
list.stream().filter(s -> s.length() > 3)
    .forEach(System.out::println);  // apple, banana

// map — 转换
list.stream().map(String::length)
    .forEach(System.out::println);  // 5, 6, 3, 3

// distinct — 去重 / sorted — 排序 / limit — 截断
list.stream().sorted().limit(2).forEach(System.out::println);
```

### 终端操作（触发计算）

```java
List<Integer> nums = List.of(1, 2, 3, 4, 5);

// collect — 收集到集合
List<Integer> even = nums.stream()
    .filter(n -> n % 2 == 0)
    .collect(Collectors.toList());  // [2, 4]

// reduce — 聚合计算
int sum = nums.stream().reduce(0, (a, b) -> a + b);  // 15

// count / max / min
long count = nums.stream().filter(n -> n > 3).count();  // 2
```

### 常用操作速查

| 操作 | 类型 | 作用 |
|------|------|------|
| `filter` | 中间 | 过滤 |
| `map` | 中间 | 转换 |
| `sorted` | 中间 | 排序 |
| `distinct` | 中间 | 去重 |
| `forEach` | 终端 | 遍历 |
| `collect` | 终端 | 收集 |
| `reduce` | 终端 | 聚合 |
| `count` | 终端 | 计数 |

### 小结

- Stream 让集合操作变得更函数式、更易读
- 中间操作惰性执行（不触发计算）
- 终端操作触发计算
- 一个 Stream 只能被消费一次
