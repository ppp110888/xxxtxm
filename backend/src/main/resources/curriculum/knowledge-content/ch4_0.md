## 集合框架概述

### 两大体系

```
Collection 接口（单列集合）         Map 接口（双列集合）
    ├── List（有序可重复）              ├── HashMap（哈希表）
    │   ├── ArrayList                  ├── TreeMap（红黑树）
    │   └── LinkedList                 └── LinkedHashMap
    └── Set（无序不可重复）
        ├── HashSet
        └── TreeSet
```

### List vs Set vs Map

| 特性 | List | Set | Map |
|------|------|-----|-----|
| 元素 | 单值 | 单值 | 键值对 |
| 有序性 | 有序 | 无序（除 LinkedHashSet） | 无序（除 TreeMap/LinkedHashMap） |
| 可重复 | 可重复 | 不可重复 | key 不可重复 |
| 常用子类 | ArrayList | HashSet | HashMap |

### 泛型保证类型安全

```java
// 没有泛型（不推荐）
List list = new ArrayList();
list.add("hello");
list.add(123);         // 可以混放不同类型
String s = (String) list.get(0);  // 需要强制转换

// 有泛型（推荐）
List<String> list = new ArrayList<>();
list.add("hello");
// list.add(123);  // 编译错误！类型安全
String s = list.get(0);  // 无需强转
```

### 小结

- Collection 和 Map 是集合框架两大体系
- List 有序可重复，Set 无序不可重复，Map 键值对
- 始终使用泛型保证类型安全
