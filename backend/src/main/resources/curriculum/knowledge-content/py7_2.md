## 代码风格与 PEP 8

### PEP 8 核心规则

**PEP 8** 是 Python 的官方代码风格指南。

### 缩进

```python
# ✅ 4 个空格缩进
def greet():
    if True:
        print("Hello")

# ❌ 不要混用 Tab 和空格
```

### 每行长度

```python
# ✅ 一行不超过 79 字符

# 长语句换行
result = function_with_long_name(
    parameter_one,
    parameter_two,
    parameter_three,
)
```

### 空行

```python
# 顶级函数和类之间 — 两个空行
def func1():
    pass


def func2():
    pass

# 类内方法之间 — 一个空行
class MyClass:
    def method1(self):
        pass

    def method2(self):
        pass
```

### 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 变量/函数 | 蛇形命名 snake_case | `student_name`, `get_score()` |
| 类 | 大驼峰 PascalCase | `StudentManager` |
| 常量 | 全大写 UPPER_CASE | `MAX_SIZE = 100` |
| 私有 | _ 前缀 | `_internal_func()` |
| 内部 | __ 前缀 | `__private_attr` |

### 注释

```python
# 注释与代码同级，更新代码时更新注释
result = 1 + 1  # 行内注释前至少两个空格

"""
文档字符串 (docstring)
用于模块、类、函数的描述
"""
```

### import 顺序

```python
# 1. 标准库
import os
import sys

# 2. 第三方库
import numpy as np
import requests

# 3. 本地模块
from mypackage import module_a
```

### 常用工具

```bash
# 自动格式化
pip install black
black myfile.py

# 代码检查
pip install flake8
flake8 myfile.py

# 导入排序
pip install isort
isort myfile.py
```

### 小结

- 4 空格缩进，行长度 ≤79
- 命名：函数/变量 snake_case，类 PascalCase，常量 UPPER_CASE
- 导入分组：标准库 → 第三方 → 本地
- 用 black/flake8 自动检查和格式化
