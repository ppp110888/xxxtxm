## Optional

### 为什么需要 Optional？

告别 NullPointerException！Optional 强制你处理可能为 null 的情况。

### 创建 Optional

```java
Optional<String> opt1 = Optional.of("Hello");     // 非 null 值
Optional<String> opt2 = Optional.ofNullable(null); // 可为 null
Optional<String> opt3 = Optional.empty();          // 空 Optional
```

### 安全取值

```java
Optional<String> opt = Optional.ofNullable(getName());

// orElse — 为 null 时返回默认值
String name = opt.orElse("未知");

// orElseGet — 为 null 时调用函数生成默认值
String name2 = opt.orElseGet(() -> "默认名");

// orElseThrow — 为 null 时抛异常
String name3 = opt.orElseThrow(() -> new RuntimeException("名称为空"));

// ifPresent — 不为 null 时执行操作
opt.ifPresent(name -> System.out.println("Hello " + name));
```

### 优雅链式处理

```java
// 传统写法（多层 null 检查）
if (user != null) {
    Address addr = user.getAddress();
    if (addr != null) {
        String city = addr.getCity();
        // ...
    }
}

// Optional 链式写法
String city = Optional.ofNullable(user)
    .map(User::getAddress)
    .map(Address::getCity)
    .orElse("未知城市");
```

### 小结

- Optional 帮助避免 NullPointerException
- `orElse` / `orElseThrow` 安全处理 null
- `map` 链式转换和取值
- 用于方法返回值，不用作字段类型
