## HashSet 与 hashCode/equals

### HashSet 特点

- 元素**不可重复**
- 基于哈希表实现，查找/添加/删除都是 O(1)
- 元素**无序**

```java
Set<String> set = new HashSet<>();
set.add("苹果");
set.add("香蕉");
set.add("苹果");  // 重复的，不会添加
System.out.println(set.size());  // 2
```

### hashCode 和 equals 契约

必须同时重写两个方法，否则 HashSet 无法正确去重：

```java
public class Student {
    private String name;
    private int age;

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof Student s)) return false;
        return age == s.age && Objects.equals(name, s.name);
    }

    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }
}
```

**规则：** equals 相等的对象，hashCode 必须相等！

### 常见错误

- ❌ 只重写 equals 不重写 hashCode → HashSet 可能存入了"重复"元素
- ✅ 同时重写 equals 和 hashCode

- ❌ 修改了 HashSet 中的元素导致 hashCode 变化 → 该元素"丢失"了
- ✅ 尽量存放不可变对象到 HashSet 中

### 小结

- HashSet 用哈希判断重复
- 自定义类放入 Set 必须重写 equals + hashCode
- equals 相等 → hashCode 必定相等（反之不一定）
