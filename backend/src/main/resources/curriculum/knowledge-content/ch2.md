# 第2章 面向对象编程

> 面向对象编程（OOP）是 Java 的核心思想。理解了 OOP，才算真正掌握了 Java。

## 本章目标

1. 理解面向对象的三大特性：封装、继承、多态
2. 掌握类与对象的定义和使用
3. 理解构造方法、访问修饰符、方法重写与重载
4. 掌握抽象类与接口的区别和使用场景
5. 了解内部类和枚举
