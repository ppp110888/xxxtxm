## 并发工具类

### CountDownLatch（倒计时门闩）

等待一组线程完成后继续：

```java
CountDownLatch latch = new CountDownLatch(3);

for (int i = 0; i < 3; i++) {
    new Thread(() -> {
        // 执行任务...
        latch.countDown();  // 完成一个任务，计数-1
    }).start();
}

latch.await();  // 阻塞等待，直到计数为0
System.out.println("所有任务完成");
```

### ConcurrentHashMap

线程安全的 HashMap，比 Hashtable 性能好：

```java
Map<String, Integer> map = new ConcurrentHashMap<>();
map.put("key", 1);
```

### Atomic 原子类

无锁的线程安全操作：

```java
AtomicInteger counter = new AtomicInteger(0);
int newVal = counter.incrementAndGet();  // 原子自增
```

### 小结

- CountDownLatch 协调多线程完成
- ConcurrentHashMap 替代同步 Map
- AtomicInteger 实现无锁自增
