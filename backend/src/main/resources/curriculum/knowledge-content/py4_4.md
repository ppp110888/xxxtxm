## 序列化与 pickle

### 什么是序列化？

**序列化** 是将 Python 对象转换为可存储/传输的字节流的过程。**反序列化** 是逆过程。

### pickle 基础

```python
import pickle

# 序列化 — 对象 → 字节
data = {"name": "小明", "scores": [85, 92, 78]}
binary = pickle.dumps(data)

# 反序列化 — 字节 → 对象
restored = pickle.loads(binary)
print(restored)  # {"name": "小明", "scores": [85, 92, 78]}
```

### pickle 文件操作

```python
import pickle

class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

s = Student("小明", 95)

# 写入文件
with open("student.pkl", "wb") as f:
    pickle.dump(s, f)

# 读取文件
with open("student.pkl", "rb") as f:
    restored = pickle.load(f)
    print(restored.name, restored.score)  # 小明 95
```

### 可序列化的类型

| 可序列化 | 不可序列化 |
|----------|-----------|
| 基本类型 (int, str, float) | 打开的文件对象 |
| 容器 (list, dict, set) | 网络连接 |
| 自定义类实例 | 线程/进程 |
| 嵌套结构 | lambda 函数 |
| datetime, Decimal 等 | 生成器对象 |

### 自定义序列化

```python
import pickle

class Player:
    def __init__(self, name, level, high_score):
        self.name = name
        self.level = level
        self.high_score = high_score

    def __getstate__(self):
        """序列化时调用：返回要保存的数据"""
        return {"name": self.name, "level": self.level, "high_score": self.high_score}

    def __setstate__(self, state):
        """反序列化时调用：从数据恢复对象"""
        self.name = state["name"]
        self.level = state.get("level", 1)
        self.high_score = state.get("high_score", 0)
```

### pickle vs JSON

| | pickle | JSON |
|------|--------|------|
| 格式 | 二进制 | 文本 (UTF-8) |
| 可读 | ❌ | ✅ |
| 跨语言 | ❌ Python 专用 | ✅ 几乎所有语言 |
| 支持类型 | Python 特有类型 | 基本类型 |
| 安全性 | ⚠️ 不信任数据有风险 | ✅ 安全 |

### 安全警告

```python
# ⚠️ 绝对不要 unpickle 不信任的数据！
# pickle.loads(untrusted_data)  # 可能执行任意代码！

# 需要跨语言/安全性 → 用 JSON
# 需要 Python 特有类型/对象 → 用 pickle
```

### 小结

- `pickle.dumps()` 序列化，`pickle.loads()` 反序列化
- 可以序列化自定义类实例
- pickle 是 Python 专用格式，不可跨语言
- **不要** unpickle 不可信来源的数据
- 跨语言场景用 JSON
