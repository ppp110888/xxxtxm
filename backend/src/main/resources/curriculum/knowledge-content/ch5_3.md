## 字符流 Reader/Writer

### 为什么需要字符流？

字节流按 byte 读取，遇到中文字符（多个 byte）会乱码。字符流按**字符**读取，自动处理编码。

### FileReader

```java
try (FileReader reader = new FileReader("input.txt", StandardCharsets.UTF_8)) {
    int c;
    while ((c = reader.read()) != -1) {
        System.out.print((char) c);
    }
}
```

### FileWriter

```java
try (FileWriter writer = new FileWriter("output.txt", StandardCharsets.UTF_8)) {
    writer.write("你好，世界！");
}
```

### 字节流 vs 字符流

| 特性 | 字节流 | 字符流 |
|------|--------|--------|
| 基类 | InputStream/OutputStream | Reader/Writer |
| 处理单位 | byte | char |
| 适用场景 | 图片、视频、二进制 | 文本文件 |
| 编码处理 | 手动 | 自动 |

### 小结

- 文本文件用字符流 Reader/Writer
- 二进制文件（图片/视频）用字节流
- 读取中文必须指定 UTF-8 编码
