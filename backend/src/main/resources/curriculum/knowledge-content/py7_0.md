## 模块与包

### 模块

一个 `.py` 文件就是一个**模块**（module）。

```python
# mymath.py
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

PI = 3.14159
```

### 导入模块

```python
# 方式1: import 模块名
import mymath
mymath.add(3, 5)

# 方式2: from 模块 import 成员
from mymath import add, PI
add(3, 5)

# 方式3: import 模块 as 别名
import numpy as np

# 方式4: from 模块 import *（不推荐）
from mymath import *
```

### if __name__ == "__main__"

```python
# mymath.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    # 直接运行此文件时执行
    print("测试: add(3, 5) =", add(3, 5))
    # 被 import 时不执行
```

### 包

**包**（package）是包含 `__init__.py` 的目录：

```
mypackage/
├── __init__.py      # 包的初始化文件
├── module_a.py
├── module_b.py
└── subpackage/
    ├── __init__.py
    └── module_c.py
```

```python
# 导入包中的模块
from mypackage import module_a
from mypackage.subpackage import module_c

# __init__.py 中可以控制导入行为
# from mypackage import * 会导入 __all__ 列表中指定的成员
```

### __init__.py

```python
# mypackage/__init__.py
__all__ = ["module_a", "module_b"]  # 控制 from package import *

from .module_a import add            # 方便用户直接导入
__version__ = "1.0.0"
```

### 相对导入（包内使用）

```python
# mypackage/module_b.py
from . import module_a          # 同包内导入
from .module_a import add       # 导入指定成员
from .subpackage import module_c  # 子包导入
```

### 小结

- `.py` 文件 = 模块，包 = 包含 `__init__.py` 的目录
- `import` 导入，支持 `as` 别名
- `if __name__ == "__main__"` 用于区分直接执行 vs 被导入
- 包内用相对导入 `from . import xxx`
