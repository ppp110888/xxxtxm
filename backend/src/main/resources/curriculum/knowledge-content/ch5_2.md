## 字节流 InputStream/OutputStream

### 读取文件

```java
// try-with-resources 自动关闭
try (FileInputStream fis = new FileInputStream("input.txt")) {
    int b;
    while ((b = fis.read()) != -1) {
        System.out.print((char) b);
    }
}

// 批量读取（更快）
try (FileInputStream fis = new FileInputStream("input.txt")) {
    byte[] buffer = new byte[1024];
    int bytesRead;
    while ((bytesRead = fis.read(buffer)) != -1) {
        System.out.write(buffer, 0, bytesRead);
    }
}

// 一次性读取全部（小文件）
byte[] allBytes = Files.readAllBytes(Path.of("input.txt"));
```

### 写入文件

```java
try (FileOutputStream fos = new FileOutputStream("output.txt")) {
    fos.write("Hello, World!".getBytes(StandardCharsets.UTF_8));
}

// Files 工具类（推荐）
Files.writeString(Path.of("output.txt"), "Hello!", StandardCharsets.UTF_8);
```

### 文件复制

```java
try (FileInputStream in = new FileInputStream("src.txt");
     FileOutputStream out = new FileOutputStream("dst.txt")) {
    byte[] buffer = new byte[1024];
    int bytesRead;
    while ((bytesRead = in.read(buffer)) != -1) {
        out.write(buffer, 0, bytesRead);
    }
}

// 或用 Files.copy（推荐）
Files.copy(Path.of("src.txt"), Path.of("dst.txt"),
           StandardCopyOption.REPLACE_EXISTING);
```

### 小结

- InputStream 读，OutputStream 写
- try-with-resources 自动关闭流
- 小文件读写用 Files 工具类最方便
