## 构造方法 __init__

### __init__ 方法

`__init__` 是 Python 的**初始化方法**，创建对象时自动调用。注意它不是真正的"构造函数" — 对象在 `__init__` 调用前已经由 `__new__` 创建。

```python
class Person:
    def __init__(self, name, age=0):
        print(f"初始化 {name}")
        self.name = name
        self.age = age

p = Person("小明", 18)  # 输出：初始化 小明
```

### __new__ — 真正的构造函数

```python
class Singleton:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

a = Singleton()
b = Singleton()
print(a is b)  # True — 同一个实例
```

### 默认参数与重载

Python 不支持方法重载，但可通过默认参数实现类似效果：

```python
class Rectangle:
    def __init__(self, width=1, height=None):
        self.width = width
        self.height = height if height is not None else width
        # 如果只传一个参数，创建正方形

r1 = Rectangle(4, 5)   # width=4, height=5
r2 = Rectangle(3)      # width=3, height=3 — 正方形
```

### 类工厂方法

```python
class Date:
    def __init__(self, year, month, day):
        self.year = year
        self.month = month
        self.day = day

    @classmethod
    def from_string(cls, date_str):
        """从字符串创建 Date 对象"""
        year, month, day = map(int, date_str.split("-"))
        return cls(year, month, day)

    @classmethod
    def today(cls):
        """创建今天的日期"""
        import datetime
        t = datetime.date.today()
        return cls(t.year, t.month, t.day)

d1 = Date(2024, 1, 15)
d2 = Date.from_string("2024-01-15")
d3 = Date.today()
```

### 常见错误

- ❌ `def __init__(self, name):` 忘记 self 参数
- ✅ 实例方法第一个参数总是 `self`
- ❌ 在 `__init__` 外定义实例属性
- ✅ 在 `__init__` 中初始化所有实例属性

### 小结

- `__init__` 是初始化方法，创建对象时自动调用
- 不支持方法重载，用默认参数替代
- `@classmethod` 可实现工厂方法模式
- `__new__` 是真正的构造函数，一般不需要重写
