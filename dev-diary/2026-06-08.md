## 技术踩坑记录

### 1. Sa-Token + Redis 冲突
- **问题**: `SaTokenDaoRedisJackson` 在无 Redis 时强制要求 `RedisConnectionFactory` bean
- **解决**: 将 `sa-token-redis-jackson` 和 `spring-boot-starter-data-redis` 从默认依赖中移除，dev环境使用 Sa-Token 内存存储

### 2. H2 时间字段 NULL 约束
- **问题**: MyBatis-Plus `@TableField(fill = FieldFill.INSERT)` 传入 NULL，H2 不触发 DEFAULT
- **解决**: 实现 `MetaObjectHandler` 自动填充 `createTime`/`updateTime`

### 3. 数据初始化时序
- **问题**: SQL脚本在 MyBatis 之前执行，用户数据应该在 Java 层初始化
- **解决**: `DataInitializer.java` (CommandLineRunner) 程序化创建用户+BCrypt加密
