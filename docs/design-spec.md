# 设计规范文档

> **项目名称：** AI 伴学编程平台
> **版本：** v1.0.0
> **最后更新：** 2026-06-08

---

## 一、 设计理念

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **以学习者为中心** | 界面简洁直观，减少认知负荷，让用户专注于代码编写 |
| **渐进式披露** | 复杂功能按学习阶段逐步展示，避免信息过载 |
| **及时反馈** | 所有操作（提交、判题、AI 诊断）都提供实时状态反馈 |
| **一致性** | 管理端与学生端共享基础 UI 语言，通过配色区分角色场景 |
| **情感化设计** | 通过热力图、成就徽章、通关动画等元素提供正向激励 |

### 1.2 角色视觉区分

| 角色 | 主题色 | 氛围 |
|------|--------|------|
| **学生端** | 科技蓝 `#409EFF` + 活力绿 `#67C23A` | 沉浸式学习，闯关激励 |
| **管理端** | 专业深蓝 `#2C3E50` + 稳重灰 `#909399` | 高效录入，数据管理 |

## 二、 布局规范

### 2.1 管理端布局

```
┌─────────────────────────────────────────────┐
│  Logo + 顶部导航栏（面包屑 + 用户头像下拉）     │
├──────────┬──────────────────────────────────┤
│          │                                   │
│  侧边栏  │         主内容区                    │
│  (深色)  │    （白色背景卡片式布局）             │
│          │                                   │
│  · 知识树│   ┌─────────────────────────┐     │
│  · 题库  │   │ Card / Table / Form     │     │
│  · 用例  │   │                         │     │
│          │   └─────────────────────────┘     │
└──────────┴──────────────────────────────────┘
```

- **侧边栏：** 宽度 220px，深色背景(#304156)，菜单项含图标+文字
- **主内容区：** padding 20px，背景色 #f0f2f5
- **内容卡片：** 白色背景，圆角 8px，阴影 `0 2px 12px rgba(0,0,0,0.06)`

### 2.2 学生端布局

```
┌─────────────────────────────────────────────┐
│  顶部导航：Logo + 导航菜单 + 头像              │
├─────────────────────────────────────────────┤
│                                              │
│            沉浸式全宽内容区                    │
│   ┌─────────────────────────────────────┐   │
│   │ 技能树 / 学习舱 / IDE / 成长中心      │   │
│   └─────────────────────────────────────┘   │
│                                              │
└─────────────────────────────────────────────┘
```

- 学生端无传统侧边栏，使用顶部 Tab 式导航
- IDE 页面使用双栏布局：左侧任务面板(35%) + 右侧编辑器(65%)

## 三、 组件规范

### 3.1 Element Plus 使用原则

- 统一使用 Element Plus 组件，不引入其他 UI 库
- 所有 Table 使用 `el-table` + `v-loading` 指令
- 所有表单使用 `el-form` + `el-form-item`，校验规则统一定义在 `formRules` 中
- 弹窗使用 `el-dialog`，确认操作使用 `el-popconfirm` 或 `el-message-box`

### 3.2 自定义组件清单（需开发）

| 组件名 | 用途 | 优先级 |
|--------|------|--------|
| `MonacoEditor.vue` | 代码编辑器封装，支持语言切换 | P0 |
| `MarkdownViewer.vue` | Markdown 渲染（讲义/题目描述） | P0 |
| `MarkdownEditor.vue` | Markdown 编辑（管理端讲义录入） | P0 |
| `SkillTreeNode.vue` | 技能树节点卡片（含状态动画） | P0 |
| `SubmissionHeatmap.vue` | 提交热力图（类 GitHub） | P1 |
| `AiDiagnosisPanel.vue` | AI 诊断浮层（SSE 流式渲染） | P2 |
| `StatusBadge.vue` | 判题状态徽章（含颜色映射） | P0 |

## 四、 响应式策略

| 断点 | 宽度 | 布局调整 |
|------|------|---------|
| 大屏 | ≥1440px | IDE 双栏 35%/65%，管理端完整侧边栏 |
| 中屏 | 1024-1439px | IDE 双栏 40%/60%，管理端收起侧边栏 |
| 小屏 | <1024px | IDE 切换为上下布局，管理端隐藏侧边栏 |

### 移动端策略（阶段三考虑）
- 技能树改为列表视图
- IDE 采用上下分屏（题目描述在上，编辑区在下）
- 隐藏热力图等非核心图表

## 五、 交互动效

| 场景 | 动效 | 说明 |
|------|------|------|
| 技能节点解锁 | 从灰色过渡到彩色 + 弹性缩放 | `transition: all 0.6s cubic-bezier(0.68, -0.55, 0.27, 1.55)` |
| 判题 AC | 绿色涟漪扩散 | 动画持续时间 1.5s |
| AI 诊断文本 | 打字机逐字输出 | `@keyframes blink-caret` 光标闪烁 |
| 页面切换 | 淡入淡出 | `<transition name="fade" mode="out-in">` |
| 列表加载 | 骨架屏 | Element Plus Skeleton 组件 |

## 六、 图标使用规范

- 统一使用 `@element-plus/icons-vue` 图标库
- 管理端菜单图标：
  - 知识树：`Collection` 或 `FolderOpened`
  - 题库：`Document`
  - 测试用例：`Files`
- 学生端导航图标：
  - 技能树：`Guide`
  - 成长中心：`DataAnalysis`
  - 错题本：`Warning`

## 七、 字体与排版

```css
:root {
  /* 字体栈 */
  --font-mono: 'JetBrains Mono', 'Fira Code', 'Cascadia Code', 'Consolas', monospace;
  --font-sans: 'PingFang SC', 'Microsoft YaHei', 'Helvetica Neue', sans-serif;

  /* 字号梯度 */
  --text-xs: 12px;   /* 辅助信息 */
  --text-sm: 13px;   /* 次要文案 */
  --text-base: 14px; /* 正文 */
  --text-lg: 16px;   /* 小标题 */
  --text-xl: 18px;   /* 标题 */
  --text-2xl: 24px;  /* 页面大标题 */
}
```

- 代码区域统一使用 `--font-mono` 等宽字体
- 正文使用 `--text-base`（14px），行高 1.6
- 标题使用 `--font-sans`，字重 600
